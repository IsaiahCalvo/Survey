## Legacy Mobile PDF Layout Groundwork

Location: [`legacy-mobile-pdf-layout-groundwork`](./legacy-mobile-pdf-layout-groundwork)

This is an older, PDF-only mobile layout preserved because its viewer layout and native PDF drawing groundwork may be useful.

Important differences:

- It does not include the current homepage.
- Some colors and visual details are outdated or wrong.
- It must not be mistaken for the current mobile design.
- It contains useful native PDF rendering, drawing, selecting, panning, and zooming groundwork.
- Its original renderer research and mobile annotation roadmap are preserved inside its `docs` folder.
