## Product bug (E2E-LINK-01)

`PdfjsLinkLayer` opened `a.url` via `window.open` / `electronAPI.openExternal` with **no protocol allowlist**.

pdf.js 6.1.200 on a generated fixture:

| URI | `url` | `unsafeUrl` | Before | After |
|---|---|---|---|---|
| `https://example.com/safe` | set | set | opened | opened |
| `mailto:isaiah@example.test` | set | set | opened | opened |
| `javascript:alert(1)` | null | set | not rendered | still not rendered; never read `unsafeUrl` |
| `data:text/html,pwned` | null | set | not rendered | same |
| `file:///etc/passwd` | null | set | not rendered | same |
| `ftp://files.example.com/x` | **set** | set | **would `window.open`** | **skipped** (not an anchor) |
| GoTo page 2 | null + dest | null | jump | jump |

Electron `shell:openExternal` already allowed only `http:` / `https:` / `mailto:`. Web Vite did not.

### Min-diff

- `src/utils/pdfExternalLink.js` — `isAllowedPdfExternalUrl` / `openPdfExternalUrl`
- `src/components/PdfjsLinkLayer.jsx` — drop disallowed `url`s before they become `<a href>`; open through the helper; `rel="noopener noreferrer"`
- Never read `a.unsafeUrl`

Not edited: `PDFViewer.jsx`, `PageAnnotationLayer.jsx`, `FabricEraserCanvas.jsx`, `SVGAnnotationLayer.jsx`, `viewerShared.js`, `package.json`, `vite.config.js`.
