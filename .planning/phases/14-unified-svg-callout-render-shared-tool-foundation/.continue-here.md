Applied as `stroke:'#000000', strokeWidth:1, strokeUniform:true` in both textbox creation paths. Text boxes with strokeWidth=0 still render borderless, so this doesn't break anything pre-existing.

- **`strokeUniform:true` for user-created textboxes only.** PDF-imported textboxes retain whatever the importer gave them (usually `null`), so their border scales with zoom (matches how Acrobat renders FreeText borders). User-created textboxes use `strokeUniform:true` so the 1px default stays visually 1px at all zoom levels — closer to "flat drawing app" expectations.

- **Border uses `effectiveWidth`/`effectiveHeight`, not `displayHeight`.** `displayHeight = effectiveHeight + descenderBuffer` (buffer added to prevent foreignObject clipping descenders like y/g/j). For the border rect we want Fabric's logical bounds, not the padded SVG-render box, so it matches the eraser-canvas render when you switch tools.
