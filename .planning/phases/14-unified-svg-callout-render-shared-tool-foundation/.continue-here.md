<the_fix>
**Strategy:** At import merge time in `src/App.jsx` around line 22214 (in the `setAnnotationsByPage` block after `importAnnotationsFromPdf` returns), split imported textboxes with callout metadata OUT of `annotationsByPage` and INTO `callouts[]` state using the Phase 14 unified callout data shape.

Pseudocode:
```js
const { annotationsByPage: importedAnnotations, unsupportedTypes } = await importAnnotationsFromPdf(pdf, { rawPdfBytes: arrayBuffer });

// NEW: split imported callouts out of the textbox pool
const importedCalloutsByPage = {};
Object.entries(importedAnnotations || {}).forEach(([pageKey, pageData]) => {
  const objects = Array.isArray(pageData?.objects) ? pageData.objects : [];
  const remaining = [];
  objects.forEach((obj) => {
    const hasCalloutIntent = obj?.data?.pdfIntent === 'FreeTextCallout';
    const hasCalloutPoints = Array.isArray(obj?.data?.pdfCalloutPoints) && obj.data.pdfCalloutPoints.length >= 2;
    if (obj?.type === 'textbox' && (hasCalloutIntent || hasCalloutPoints)) {
      const calloutEntry = convertImportedCalloutToCalloutState(obj, pageKey);
      if (calloutEntry) {
        (importedCalloutsByPage[pageKey] = importedCalloutsByPage[pageKey] || []).push(calloutEntry);
        return; // DO NOT keep in annotations
      }
    }
    remaining.push(obj);
  });
  pageData.objects = remaining;
});

// Then setCallouts with importedCalloutsByPage merged in (preserving user-created callouts)
```
