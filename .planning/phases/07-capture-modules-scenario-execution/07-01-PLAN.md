  <action>
Create four focused capture modules in `debug/lib/`. Each module owns exactly one JSONL file (or screenshot files) and has a clear, small API.

**screenshot.mjs** (CAPT-01, CAPT-08):
- Export `async function takeScreenshot(page, sessionDir, stepNum, timing, actionName)`.
- Before capture: call `await page.evaluate(() => window.__debugReady.waitFor('ready', { timeout: 30000 }))` to satisfy CAPT-08 (readiness-gated screenshots).
- Get sessionMs via `await page.evaluate(() => performance.now())`.
- Build filename per locked convention: `step-${stepStr}_${msStr}ms_${timing}-${safeName}.png` where stepStr is zero-padded to 2 digits, msStr is zero-padded to 5 digits, safeName is actionName lowercased with non-alphanumeric chars replaced by hyphens.
- Call `page.screenshot({ path: path.join(sessionDir, filename), fullPage: false })`.
- Return `{ filename, sessionMs }`.
- Use `import path from 'node:path'`.

**console-capture.mjs** (CAPT-03):
- Export `function startConsoleCapture(page, sessionDir)` and `function stopConsoleCapture(page)`.
- startConsoleCapture: Register a `page.on('console', handler)` listener. The handler:
  - Gets sessionMs via `await page.evaluate(() => performance.now())` (wrapped in try/catch, fallback to -1 if page closed).
  - Builds entry: `{ sessionMs: Math.round(sessionMs), level: msg.type(), text: msg.text(), location: msg.location() }`.
  - If `msg.type() === 'error'`, add `stackTrace: msg.text()` to entry.
  - Appends JSON line to `path.join(sessionDir, 'console.jsonl')` via `appendFileSync`.
- stopConsoleCapture: Remove the listener via `page.removeListener('console', handler)`.
- Use module-level `let handler = null` for reference tracking.
- Use `import { appendFileSync } from 'node:fs'` and `import path from 'node:path'`.

**state-capture.mjs** (CAPT-04):
- Export `async function captureState(page, sessionDir, stepNum, actionName)`.
- Call `page.evaluate(() => window.__debugBridge.snapshot({ drainMutations: true }))` to get bridge snapshot with drained mutations.
- Build entry with fields per locked decision: `{ sessionMs: snapshot.sessionMs, step: stepNum, action: actionName, zoomLevel, renderedScale, targetScale, freezeState, canvasContainerCount, pageStatus, mutations, signals }`.
- Append JSON line to `path.join(sessionDir, 'state.jsonl')` via `appendFileSync`.
- Return the entry for caller inspection.

**perf-capture.mjs** (CAPT-07):
- Export `async function startPerfCapture(page, sessionDir)` and `async function stopPerfCapture(page, sessionDir)`.
- startPerfCapture:
  - Open CDP session: `const cdpClient = await page.context().newCDPSession(page)`.
  - Enable Performance domain: `await cdpClient.send('Performance.enable')`.
  - Start polling interval at 500ms. Each poll: call `cdpClient.send('Performance.getMetrics')`, get sessionMs via `page.evaluate(() => performance.now())`, build entry `{ sessionMs, type: 'cdp', metrics: Object.fromEntries(metrics.map(m => [m.name, m.value])) }`, append to `performance.jsonl`. Wrap poll body in try/catch (page may close).
  - Store cdpClient and pollInterval in module-level variables.
- stopPerfCapture:
  - Clear the poll interval.
  - Final flush: collect performance marks from browser via `page.evaluate(() => performance.getEntriesByType('mark').filter(m => m.name.includes('_')).map(m => ({ name: m.name, startTime: m.startTime, detail: m.detail })))`.
  - Write each mark as `{ sessionMs: mark.startTime, type: 'mark', name: mark.name, detail: mark.detail }` to `performance.jsonl`.
  - Detach CDP session: `await cdpClient.detach()`.

All four modules: use `appendFileSync` for JSONL writes (atomic for lines under 4096 bytes). Each JSONL file has exactly ONE writer module to prevent corruption.

**capture.mjs** (CAPT-02, CAPT-06):
- Import all four leaf modules and session.mjs utilities.
- Export `class CaptureContext` with this API:

```
constructor(scenarioName, page)
```
- Stores page reference, scenarioName, initializes stepCount = 0.
- Calls `createSession(scenarioName, getSessionBaseDir())` to create session folder.
- Stores sessionDir, manifest, and empty artifacts array.

```
async start()
```
- Records `captureStartMs` from browser via `page.evaluate(() => performance.now())` and stores in `this.manifest.captureStartMs` (CAPT-06: for video alignment, so video frame offset = sessionMs - captureStartMs).
- Calls `startConsoleCapture(this.page, this.sessionDir)`.
- Calls `await startPerfCapture(this.page, this.sessionDir)`.
- Takes baseline screenshot: `await takeScreenshot(this.page, this.sessionDir, 0, 'baseline', 'initial-state')` producing `step-00_00000ms_baseline-initial-state.png` (per locked convention).

```
async step(actionName, actionFn)
```
- Increments stepCount.
- Takes "before" screenshot: `await takeScreenshot(page, sessionDir, stepCount, 'before', actionName)`.
- Captures state snapshot before action: `await captureState(page, sessionDir, stepCount, actionName)`.
- Executes the action: `await actionFn()`.
- Waits for readiness: `await page.evaluate(() => window.__debugReady.waitFor('ready', { timeout: 30000 }))`.
- Takes "after" screenshot: `await takeScreenshot(page, sessionDir, stepCount, 'after', actionName)`.

```
async finalize(result, criteriaResults)
```
- Calls `stopConsoleCapture(this.page)`.
- Calls `await stopPerfCapture(this.page, this.sessionDir)`.
- Builds artifacts list by scanning sessionDir for created files (screenshots, JSONL files).
- Stores `criteriaResults` in manifest (for CAPT-05 pass/fail detail).
- Calls `finalizeSession(this.sessionDir, this.manifest, result, artifacts)`.
- Returns `this.sessionDir` for caller reference.

```
getSessionDir()
```
- Returns `this.sessionDir` for callers that need to save additional artifacts (like video).

**Video handling note:** Video is NOT managed by CaptureContext because Playwright video lifecycle requires `page.video().saveAs()` AFTER the test body (in afterEach hook). CaptureContext records `captureStartMs` so video timestamps can be correlated. The scenario test file handles video.saveAs() in its own afterEach.
