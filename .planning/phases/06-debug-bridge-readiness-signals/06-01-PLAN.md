  <name>Task 1: Create debugBridge.js module with snapshot(), RingBuffer, MutationObserver, and debugMark()</name>
  <files>src/utils/debugBridge.js</files>
  <action>
Create `src/utils/debugBridge.js` as the core debug bridge module. Everything in this file is wrapped in `import.meta.env.DEV` guards or is a no-op export that Vite dead-code-eliminates in production.

**RingBuffer class (internal):**
- Fixed-capacity circular array (default 100 entries, configurable via constructor)
- `push(item)` assigns sequential `seq` number, overwrites oldest when full
- `drain()` returns ordered array of all items and resets buffer (atomic read+clear)
- `toArray()` returns ordered array without clearing

**debugMark(name, detail) export:**
- If `import.meta.env.DEV`: calls `performance.mark(name, detail != null ? { detail } : undefined)`
- The `if (import.meta.env.DEV)` block ensures Vite strips the entire function body in production
- Naming convention is flat `category_event` (e.g., `zoom_start`, `pal_mount`, `fabric_renderStart`)

**register(sources) / unregister() exports:**
- `register({ refs, getState, getPageLayerContainer })` stores a module-level `registered` variable
- `refs` contains React ref objects (read `.current` at snapshot time, never at registration)
- `getState()` returns a plain object with current React state values (renderedScale, cssScale, isZooming, scale, pageNum, visiblePages, syncfusionPageContainers)
- `getPageLayerContainer` is a function that returns the `.e-pv-page-container` DOM element
- On register, if `getPageLayerContainer` returns a DOM element, immediately attach the MutationObserver. If not yet available, set up a lazy attachment that tries on first `snapshot()` call
- `unregister()` disconnects MutationObserver, clears registered, cleans up window globals

**MutationObserver (internal, set up during register):**
- Observe the element from `getPageLayerContainer()` with `{ childList: true, subtree: true }`
- Callback: for each mutation, iterate `mutation.addedNodes` and `mutation.removedNodes`
- For each node, check `node.classList?.contains('e-pv-page-div')` -- skip all others
- Extract page number from `node.dataset?.pageNumber` or `node.id?.match(/_pageDiv_(\d+)$/)` (add 1 for 0-indexed ID)
- Check `hasAnnotationLayer`: `!!node.querySelector('.annotation-layer, [data-annotation-layer]')` (the PAL container)
- Check `hasFabricCanvas`: `!!node.querySelector('.canvas-container')`
- Push to ring buffer: `{ type: 'added'|'removed', pageNumber, sessionMs: performance.now(), hasAnnotationLayer, hasFabricCanvas, seq (from ring buffer) }`
- For 'removed' events, find the last 'added' record for that page and set `pairSeq` on both records for destroy-to-recreate gap analysis
- This observer is SEPARATE from SyncfusionPDFContainer's existing observer -- two observers on the same target is fine, browser batches mutations independently

**snapshot(options) export:**
- If `!registered`, return `null`
- Build flat JSON object:
  - `sessionMs`: `performance.now()`
  - `zoomLevel`: `registered.refs.scale?.current ?? getState().scale ?? null` (the actual zoom percentage, e.g., 100, 150)
  - `renderedScale`: from `getState().renderedScale`
  - `targetScale`: from `getState().cssScale` (this is the target during transform)
  - `portalHostCount`: `Object.keys(registered.refs.portalHosts?.current || {}).length`
  - `freezeState`: `{ zoomOverlayTransformActive: refs.zoomOverlayTransformActive?.current, scaleConfirmPending: refs.scaleConfirmPending?.current }` (object with both booleans, so caller sees which freeze mechanism is active)
  - `canvasContainerCount`: `document.querySelectorAll('.canvas-container').length`
  - `isZooming`: from `getState().isZooming`
  - `currentPage`: from `getState().pageNum`
  - `visiblePages`: from `getState().visiblePages` (array)
  - `pageStatus`: for each visible page, compute 4-layer status object: `{ page: N, visible: true, syncfusionDom: bool, palMounted: bool, fabricCanvas: bool }`. Check syncfusionDom by querying `.e-pv-page-div` with that page number in DOM. Check palMounted/fabricCanvas similarly inside the page div
- If `options.include` is an array:
  - If includes `'debug'`: merge `window.pdfDebug?.dump()` result under a `debug` key
  - If includes `'perf'`: merge `window.pdfPerf?.getSummary?.()` result under a `perf` key
- If `options.drainMutations === true`: add `mutations` key with ring buffer `.drain()` result
- If `options.drainMutations === false` or not specified, add `mutations` key with ring buffer `.toArray()` result
- Ensure JSON-serializability: wrap the entire return in a try/catch with `JSON.parse(JSON.stringify(result))`. If it throws, return a fallback with `{ error: 'snapshot serialization failed', sessionMs }`

**Window global setup (at module load):**
- `if (import.meta.env.DEV)` block that sets `window.__debugBridge = { snapshot, debugMark }` at module import time
- Cleanup in `unregister()` deletes the window global

The module exports: `{ register, unregister, snapshot, debugMark }`
