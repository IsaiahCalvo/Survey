**Create `src/hooks/useFabricCanvas.js`** -- shared Canvas lifecycle hook.

This hook encapsulates Fabric.js Canvas creation, ref management, and synchronous disposal.

```
Export: useFabricCanvas({ canvasElRef, options })
Returns: { fabricRef }
```

Implementation details:
- Accept `canvasElRef` (React ref to `<canvas>` element) and `options` object `{ width, height, backgroundColor, isDrawingMode, selection, enableRetinaScaling, stopContextMenu }`
- In a `useEffect` (deps: `[]` -- mount only), create `new fabric.Canvas(canvasElRef.current, options)`, store in `fabricRef.current`
- Cleanup function: call `canvas.off()` then `canvas.dispose()` synchronously (Fabric 5.5.2 dispose is sync). Wrap in try/catch, log errors with `console.error('Canvas disposal error:', e)`. Set `fabricRef.current = null`.
- Return `{ fabricRef }` so the consumer can access the raw Fabric canvas for event binding, brush setup, etc.
- **Do NOT use setZoom in this hook** -- that responsibility belongs to the consumer component after mount.

**Create `src/components/FabricDrawingCanvas.jsx`** -- pen + highlighter drawing Canvas.

Props:
```
{
  pageNumber,       // number -- current PDF page
  pageWidth,        // number -- unscaled PDF page width (e.g., 612)
  pageHeight,       // number -- unscaled PDF page height (e.g., 792)
  activeTool,       // 'pen' | 'highlighter'
  strokeColor,      // string -- user-selected pen color (e.g., '#ff0000')
  highlightColor,   // string -- highlight color (e.g., 'rgba(255, 193, 7, 0.3)')
  strokeWidth,      // number -- user-selected stroke width (default 3)
  annotations,      // Fabric.js JSON { objects: [...] } -- current page annotations
  onStrokeCommit,   // (updatedAnnotationsJSON) => void -- called on each completed stroke
  selectedModuleId, // string|null -- for metadata tagging
  activeRegionId,   // string|null -- for metadata tagging
  zoomGeneration,   // number -- incremented by App.jsx when zoom starts; triggers flush of in-progress stroke
}
```

Implementation details:

1. **Refs:**
   - `canvasElRef` = useRef(null) -- the `<canvas>` DOM element
   - `containerRef` = useRef(null) -- the wrapper div for container-aware measurement
   - `fabricRef` = useRef(null) -- Fabric Canvas instance (from useFabricCanvas)
   - `sessionPathsRef` = useRef([]) -- array of Fabric path objects added during this session (for undo sync)
   - `annotationsRef` = useRef(annotations) -- kept in sync with annotations prop for closure access
   - `previousObjectCountRef` = useRef(annotations?.objects?.length ?? 0) -- count of annotations BEFORE any drawing session strokes, initialized at mount

2. **Canvas initialization (useEffect, deps: []):**
   - Call `useFabricCanvas` with canvasElRef and options: `{ backgroundColor: 'transparent', isDrawingMode: true, selection: false, enableRetinaScaling: true, stopContextMenu: true }`
   - After canvas is created, apply container-aware sizing:
     - Measure `containerRef.current.offsetWidth / pageWidth` to get `effectiveScale`
     - Call `canvas.setZoom(effectiveScale)` so paths are in unscaled page coordinates (SVG viewBox space)
     - Set canvas dimensions: `canvas.setWidth(Math.floor(pageWidth * effectiveScale))` and `canvas.setHeight(Math.floor(pageHeight * effectiveScale))`
   - Set up PencilBrush: `canvas.freeDrawingBrush = new fabric.PencilBrush(canvas)`
   - Set cursor: `canvas.defaultCursor = 'crosshair'`; `canvas.freeDrawingCursor = 'crosshair'`

3. **Brush configuration (useEffect, deps: [activeTool, strokeColor, highlightColor, strokeWidth]):**
   - If `!fabricRef.current` return
   - Get brush: `const brush = fabricRef.current.freeDrawingBrush`
   - If `activeTool === 'highlighter'`:
     - `brush.color = highlightColor`
     - `brush.width = Math.max(strokeWidth, 8)` (minimum 8px for visible highlights)
   - Else (pen):
     - `brush.color = strokeColor`
     - `brush.width = strokeWidth`

4. **path:created handler (useEffect, deps: []):**
   - Bind `canvas.on('path:created', handler)` in the mount useEffect
   - In handler:
     - `e.path.set({ strokeUniform: true, perPixelTargetFind: true, uniformScaling: false, centeredRotation: true })`
     - If `activeTool` ref is `'highlighter'`: `e.path.set({ globalCompositeOperation: 'multiply' })`
     - Assign metadata: if `selectedModuleIdRef.current` then `e.path.set({ moduleId: selectedModuleIdRef.current })`. Same for `activeRegionIdRef.current` -> `regionId`.
     - Serialize: `const pathJSON = e.path.toJSON(['strokeUniform', 'spaceId', 'moduleId', 'regionId', 'data', 'name', 'highlightId', 'needsBIC', 'globalCompositeOperation', 'layer', 'isPdfImported', 'pdfAnnotationId', 'pdfAnnotationType'])`
     - Push `e.path` to `sessionPathsRef.current`
     - Build updated annotations: `const updated = { ...annotationsRef.current, objects: [...(annotationsRef.current?.objects || []), pathJSON] }`
     - Call `onStrokeCommitRef.current(updated)`
   - Use refs for `activeTool`, `selectedModuleId`, `activeRegionId`, `onStrokeCommit`, and `annotations` to avoid stale closures. Create corresponding refs: `activeToolRef`, `selectedModuleIdRef`, `activeRegionIdRef`, `onStrokeCommitRef`. Sync them via separate useEffects.

5. **Undo sync (useEffect, deps: [annotations]):**
   - Compare `annotations.objects.length` with `sessionPathsRef.current.length + previousObjectCountRef.current`
   - If objects decreased (undo happened): pop last from `sessionPathsRef.current`, call `fabricRef.current.remove(poppedPath)`, call `fabricRef.current.renderAll()`
   - Track `previousObjectCountRef` = annotations.objects.length at mount time (the count BEFORE any drawing session strokes)

6. **Zoom-triggered flush (useEffect, deps: [zoomGeneration]):**
   - This useEffect watches the `zoomGeneration` prop. When it changes (App.jsx increments it at zoom-start), force-complete any in-progress stroke:
   - `if (fabricRef.current?._isCurrentlyDrawing)`: call `fabricRef.current.freeDrawingBrush.onMouseUp({ e: new MouseEvent('mouseup') })` to force-complete the stroke. This triggers `path:created` which commits the stroke via the handler above.
   - Skip on first render (use a ref to track whether this is the initial mount, e.g., `const initialZoomGenRef = useRef(zoomGeneration)`; skip if `zoomGeneration === initialZoomGenRef.current`).

7. **Pre-unmount commit (EDIT-09):**
   - In the useEffect cleanup (the same one that calls dispose), check if there is a Fabric path currently being drawn: `if (fabricRef.current?._isCurrentlyDrawing)` -- Fabric.js sets this during active freeDrawing. If so, the path:created won't have fired yet. Call `fabricRef.current.freeDrawingBrush.onMouseUp({ e: new MouseEvent('mouseup') })` to force-complete the stroke before disposal. This triggers path:created which commits the stroke via the handler.

8. **Render:**
   ```jsx
   return (
     <div
       ref={containerRef}
       style={{
         position: 'absolute', top: 0, left: 0, width: '100%', height: '100%',
         pointerEvents: 'auto', zIndex: 101,
       }}
     >
       <canvas ref={canvasElRef} />
     </div>
   );
   ```

9. **Export:** Default export, wrapped in `memo`.
