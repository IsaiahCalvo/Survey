**Create `src/components/FabricEraserCanvas.jsx`** -- eraser Canvas with full-page annotation loading.

Props:
```
{
  pageNumber,       // number
  pageWidth,        // number -- unscaled PDF page width
  pageHeight,       // number -- unscaled PDF page height
  annotations,      // Fabric.js JSON { objects: [...] }
  onEraseCommit,    // (updatedAnnotationsJSON) => void
  eraserSize,       // number -- eraser radius in page coordinates (default 20)
  zoomGeneration,   // number -- incremented by App.jsx when zoom starts; triggers flush of in-progress erase gesture
}
```

Implementation details:

1. **State and Refs:**
   - `const [isLoading, setIsLoading] = useState(true)` -- controls cursor state for rendering
   - `const isLoadingRef = useRef(true)` -- **CRITICAL: ref mirror of isLoading for use in mouse:down handler.** The mouse:down handler is bound in `useEffect([])` and would capture the initial `isLoading=true` state value forever due to stale closure. The ref is always current.
   - `canvasElRef`, `containerRef`, `fabricRef` -- same as FabricDrawingCanvas
   - `eraserPathRef = useRef([])` -- accumulates eraser stroke points during a gesture
   - `isErasingRef = useRef(false)` -- tracks active erase gesture
   - `annotationsRef = useRef(annotations)` -- for closure access
   - `onEraseCommitRef = useRef(onEraseCommit)` -- for closure access
   - `mountedRef = useRef(true)` -- guards async callback after unmount

2. **Canvas initialization (useEffect, deps: []):**
   - Call `useFabricCanvas` with options: `{ backgroundColor: 'transparent', isDrawingMode: false, selection: false, enableRetinaScaling: true, stopContextMenu: true, skipTargetFind: true }`
   - Container-aware sizing: measure `containerRef.current.offsetWidth / pageWidth` -> `effectiveScale`. Set `canvas.setZoom(effectiveScale)`, `canvas.setWidth(Math.floor(pageWidth * effectiveScale))`, `canvas.setHeight(Math.floor(pageHeight * effectiveScale))`
   - Set cursors: `canvas.defaultCursor = 'none'`, `canvas.hoverCursor = 'none'`, `canvas.moveCursor = 'none'` (the existing eraser circle overlay in App.jsx provides the visual cursor)
   - **Load annotations:** Call `fabric.util.enlivenObjects(annotations.objects || [], callback)`. In the callback:
     - Guard: `if (!mountedRef.current) return`
     - For each enlivened object and its source data (`annotations.objects[index]`):
       - `obj.set({ strokeUniform: true, selectable: false, evented: false })`
       - Copy metadata: spaceId, moduleId, regionId, layer, highlightId, needsBIC, globalCompositeOperation, data, name, isPdfImported, pdfAnnotationId, pdfAnnotationType
       - If `obj.highlightId || obj.needsBIC`: `obj.set({ globalCompositeOperation: 'multiply' })`
       - `canvas.add(obj)`
     - After loop: `canvas.renderAll()`
     - `setIsLoading(false)`
     - `isLoadingRef.current = false` -- **CRITICAL: update the ref alongside state so mouse:down guard reads current value**
   - Cleanup: `mountedRef.current = false` before dispose

3. **Eraser gesture handling (mouse:down, mouse:move, mouse:up):**
   - Bind in the mount useEffect:

   **mouse:down handler:**
   - If `isLoadingRef.current` is true, return (prevent erasing before load complete). **MUST check the ref, NOT the state variable, because this handler is bound in `useEffect([])` and the state value would be stale (always `true`).**
   - `isErasingRef.current = true`
   - Get pointer: `const pointer = canvas.getPointer(e.e)` -- gives coordinates in page space (because setZoom)
   - `eraserPathRef.current = [['M', pointer.x, pointer.y]]`

   **mouse:move handler:**
   - If `!isErasingRef.current` return
   - Get pointer, push `['L', pointer.x, pointer.y]` to `eraserPathRef.current`

   **mouse:up handler:**
   - If `!isErasingRef.current` return
   - `isErasingRef.current = false`
   - Get the final eraser path data from `eraserPathRef.current`
   - If path has fewer than 2 points, return (no meaningful gesture)

   **Apply eraser to canvas objects:**
   - Get all canvas objects: `const objects = canvas.getObjects()`
   - For each object:
     - Skip if object has no path data (e.g., rect, ellipse -- eraser only works on path-type objects in the existing PAL implementation; non-path objects would need different handling. Follow the same approach as PAL: only erase path-type objects).
     - Get the object's path data (from `obj.path`)
     - Get the object's transform matrix: `obj.calcTransformMatrix()`
     - Call `splitPathDataByEraser(obj.path, eraserPathRef.current, transformMatrix)`
     - If result is empty (fully erased): `canvas.remove(obj)`
     - If result differs from original: update `obj.path` with the new path data, call `obj.setCoords()`, mark object as dirty
   - `canvas.renderAll()`

   **Commit erased result:**
   - Serialize the entire canvas: Build the updated JSON by iterating canvas objects, serializing each with `obj.toJSON(CUSTOM_PROPS)` (same CUSTOM_PROPS array as FabricDrawingCanvas), and assembling into `{ objects: [...] }`
   - Note: objects that were removed from canvas are gone from this serialization (that's the erase effect)
   - Call `onEraseCommitRef.current(updatedJSON)`

4. **Zoom-triggered flush (useEffect, deps: [zoomGeneration]):**
   - This useEffect watches the `zoomGeneration` prop. When it changes (App.jsx increments it at zoom-start), force-complete any in-progress erase gesture:
   - If `isErasingRef.current === true`: execute the same mouse:up logic (apply eraser path to objects, serialize, commit). Then reset `isErasingRef.current = false` and clear `eraserPathRef.current`.
   - Skip on first render (use a ref to track whether this is the initial mount, e.g., `const initialZoomGenRef = useRef(zoomGeneration)`; skip if `zoomGeneration === initialZoomGenRef.current`).

5. **Pre-unmount commit (EDIT-09):**
   - In useEffect cleanup: if `isErasingRef.current === true` (user was mid-erase when tool switched), force mouse:up logic: apply the partial eraser path to objects and commit. Then proceed with canvas disposal.

6. **Render:**
   ```jsx
   return (
     <div
       ref={containerRef}
       style={{
         position: 'absolute', top: 0, left: 0, width: '100%', height: '100%',
         pointerEvents: 'auto', zIndex: 101,
         cursor: isLoading ? 'wait' : 'none',
       }}
     >
       <canvas ref={canvasElRef} />
     </div>
   );
   ```

7. **Export:** Default export, wrapped in `memo`.

**IMPORTANT implementation note on eraser geometry:** The existing PAL eraser logic (lines 2352-2714) is the authoritative reference. It handles:
- Building an eraser stroke path from mouse events
- For each canvas object that intersects the eraser: calling the geometry functions to split/subtract
- Handling transform matrices for rotated/scaled objects
- The executor MUST read the full PAL eraser section (lines 2352-2714) and port the intersection/subtraction loop. Do not simplify or skip the transform matrix handling -- it is load-bearing for correctness with rotated annotations.

**IMPORTANT implementation note on isLoadingRef:** The `isLoadingRef` pattern is essential. Without it, the `mouse:down` handler (bound once in `useEffect([])`) captures the initial `isLoading = true` state value and never sees updates. The ref must be set to `false` in the same callback as `setIsLoading(false)`, inside the `enlivenObjects` callback.
