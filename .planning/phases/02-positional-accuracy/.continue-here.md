<decisions_made>

- **stopPropagation + capture phase**: Necessary because Syncfusion has its own internal ctrl+wheel zoom handler. `preventDefault()` alone doesn't stop JavaScript handlers — only browser defaults. Capture phase ensures our handler fires before Syncfusion's.
- **Page container transforms vs overlay-only**: Must transform the entire Syncfusion page container (which hosts both the PDF canvas and the portaled annotation overlay). Overlay-only transforms make annotations scale while the page stays frozen — visually wrong.
- **Update base scale before zoomTo in settle timer**: When Syncfusion re-renders after zoomTo, it creates new page containers. The overlay content ref callback checks `zoomOverlayTransformActiveRef` and computes `ratio = appScale / baseScale`. By setting baseScale = finalScale before zoomTo, the ratio computes to ≈1, preventing double-transforms on new containers.
- **Transform origin 'top left'**: Consistent with existing overlay transforms. Cursor-centric zoom (center of viewport) is a separate Phase 2 concern.
</decisions_made>
