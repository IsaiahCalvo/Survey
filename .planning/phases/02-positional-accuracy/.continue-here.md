<decisions_made>

- **Ref object vs boolean prop for zoom active signal**: Boolean prop (`isZoomOverlayActive={ref.current}`) was stale — refs don't trigger re-renders, so PAL never saw the true value during zoom. Also caused extra re-renders when other state changes made App re-render. Switched to passing ref object itself (`zoomOverlayActiveRef={ref}`), read `.current` only in settle timer callback.
- **Defer zoomTo instead of guarding PAL only**: PAL guard alone was insufficient — Syncfusion's own `zoomTo()` re-render destroys/recreates DOM, causes 1-4s blocking. The wheel handler must not call `zoomTo()` during active zoom.
- **300ms settle timer for deferred zoomTo**: Matches existing settle timer convention in the codebase. After 300ms of no wheel events, calls `zoomTo()` once → single Syncfusion re-render at final level.
- **Track zoom level via scaleRef.current**: When overlay is active, `viewer.zoomValue` is stale (we never called `zoomTo()`). Use `scaleRef.current * 100` for delta calculation instead.
</decisions_made>
