<decisions_made>

- **Root cause was `setScale` during zoom, NOT portal hosts** — The previous session's portal host freeze fix addressed a real issue (portals into disconnected DOM), but the dominant cause of disappearance was `setScale(nextScale)` being called on every zoom event. This triggered React re-renders that passed new `layerScale` to PAL, causing canvas destruction/rebuild. CSS transforms on the wrapper were applied but useless because the CONTENT was being destroyed.
- **Defer scale via `syncfusionPendingZoomScaleRef`** — Reused existing mechanism that was gated behind disabled feature flags. Now also activates when `zoomOverlayTransformActiveRef` is true (independent of feature flags).
- **Freeze `layerScale` via ref check in render** — `zoomOverlayTransformActiveRef` is a ref (not state), so reading it in render doesn't create subscriptions. It will have the correct value when re-renders happen for other reasons (container mutations, etc.).
- **Two-phase cleanup over immediate cleanup** — Safety timer now uses `syncfusionScaleConfirmPendingRef` to wait for PAL to confirm canvas rebuild before removing CSS transforms, preventing the visual flash.
- **Cancel confirm timer on re-zoom** — If user starts zooming again while the 800ms confirm timer is running from a previous settle, the timer is cancelled to prevent force-cleanup during active zoom.
</decisions_made>
