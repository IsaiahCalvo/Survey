**Step 1: Add `computeViewportCenterAnchor` to `src/utils/zoomAnchorProjection.js`**

Add a second named export:
```javascript
export const computeViewportCenterAnchor = (containerElement) => {
  if (!containerElement) return null;
  const rect = containerElement.getBoundingClientRect();
  return {
    x: rect.width / 2 + containerElement.scrollLeft,
    y: rect.height / 2 + containerElement.scrollTop
  };
};
```

This is a convenience function used when toolbar zoom (no cursor position) needs a viewport-center anchor. JSDoc with @param/@returns.
