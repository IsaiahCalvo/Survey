<objective>
Replace hardcoded `transformOrigin: 'top left'` in both overlay transform functions with per-page cursor-relative transform-origin, so annotations scale from the correct anchor point during zoom.

Purpose: This is the core fix for positional accuracy. Currently annotations drift away from their correct positions during zoom because the CSS scale transform expands from the top-left corner of each page's overlay, rather than from the point the user is zooming around. By projecting the global zoom anchor (cursor + scroll) into each page's local coordinate system, annotations will track page content exactly.

Output: A utility function `computePageLocalAnchor` and modified `applySyncfusionOverlayTransformSync` + `handleSyncfusionZoomChange` in App.jsx that use per-page cursor-relative transform-origins.
</objective>

**Step 1: Create `src/utils/zoomAnchorProjection.js`**

Create a utility module with a single exported function:

```javascript
export const computePageLocalAnchor = (pageNumber, pageContainers, containerElement, globalAnchor)
```

This function projects a global zoom anchor (cursor + scroll in document coordinates) into page-local coordinates for use as CSS `transformOrigin`.

Logic:
1. If `globalAnchor` is null/undefined or `containerElement` is null, return `null` (caller falls back to `'top left'`).
2. Look up `pageHost` from `pageContainers[pageNumber]`. If not found or not `isConnected`, return `null`.
3. Get `containerRect = containerElement.getBoundingClientRect()` and `pageRect = pageHost.getBoundingClientRect()`.
4. Compute page position in document coordinates:
   - `pageDocX = pageRect.left - containerRect.left + containerElement.scrollLeft`
   - `pageDocY = pageRect.top - containerRect.top + containerElement.scrollTop`
5. Project global anchor to page-local:
   - `localX = globalAnchor.x - pageDocX`
   - `localY = globalAnchor.y - pageDocY`
6. Return `{ x: localX, y: localY }`.

IMPORTANT: The local anchor CAN be outside page bounds (negative or > page dimensions) for pages far from the cursor. This is mathematically correct -- CSS transform-origin works with any coordinate. Do NOT clamp.

Follow project conventions: camelCase function name, named export, JSDoc with @param/@returns, `.js` extension, 2-space indent, single quotes.
