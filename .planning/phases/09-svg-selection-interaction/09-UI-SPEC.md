# Phase 9 — UI Design Contract

> Visual and interaction contract for SVG selection, drag, resize, and rotation. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (SVG graphics layer -- no component library) |
| Preset | not applicable |
| Component library | none (native SVG elements + React) |
| Icon library | Custom SVG inline (rotate-icon.svg already in assets) |
| Font | not applicable (annotation layer, no text UI) |

**Rationale:** Phase 9 is an SVG annotation interaction layer rendered inside an `<svg viewBox>` element. There are no form inputs, buttons, modals, or page layouts. All visual elements are SVG primitives (circles, rects, lines, paths). No design system toolkit applies.

## Interaction States

### Idle State (no selection)

| Element | Visual | Cursor |
|---------|--------|--------|
| Annotation (not hovered) | Normal SVG rendering from Phase 8 | `default` (inherited from page) |
| SVG background | Transparent, receives pointer events for deselect | `default` |

### Hover State

| Element | Visual | Cursor |
|---------|--------|--------|
| Annotation on hover | 2px outline in `#4a90e2` at 40% opacity around annotation bounds | `pointer` |
| Annotation on hover (already selected) | Selection handles visible, no extra hover outline | `move` |

SVG implementation: Hover outline as a `<rect>` with `stroke="#4a90e2" stroke-opacity="0.4" stroke-width={2 * inverseScale}` rendered conditionally.

### Selected State (single)

| Element | Visual | Cursor |
|---------|--------|--------|
| Selected annotation | Dashed bounding box + 8 resize handles + rotation handle | `move` (on body), resize cursor (on handles) |
| Non-selected annotation | Normal rendering, still hoverable | `pointer` on hover |
| SVG background click | Deselects all (INTR-09) | `default` |

### Multi-Select State

| Element | Visual | Cursor |
|---------|--------|--------|
| Each selected annotation | Individual dashed bounding boxes (no handles on individual items) | `move` |
| Group bounding box | Dashed rect in `#4a90e2` at 60% opacity enclosing all selected, with 8 corner/edge handles | `move` (on body), resize cursor (on handles) |
| Shift+click on unselected | Adds to selection | `pointer` |
| Shift+click on selected | Removes from selection | `pointer` |

### Dragging State

| Element | Visual | Cursor |
|---------|--------|--------|
| Dragged annotation(s) | SVG `translate()` transform applied in real-time, annotation follows cursor directly | `grabbing` |
| Bounding box + handles | Move with annotation | -- |
| Page boundary | Constrain: annotation cannot be dragged beyond `0,0` to `pageWidth,pageHeight` | -- |

During drag: only visual position updates (SVG `transform` attribute). No data mutation until `pointerup`.

### Resizing State

| Element | Visual | Cursor |
|---------|--------|--------|
| Resized annotation | Width/height/scale updates in real-time following handle drag | Handle-appropriate resize cursor |
| Shift held | Aspect ratio locked during resize | Same cursor |
| Opposite corner | Anchored (does not move) | -- |

During resize: update `scaleX`/`scaleY` (not `width`/`height`) to match Fabric.js JSON conventions. Commit on `pointerup`.

### Rotating State

| Element | Visual | Cursor |
|---------|--------|--------|
| Rotated annotation | Rotation around center point, bounding box rotates with it | `crosshair` |
| Angle | Computed from center to pointer, normalized 0-360 degrees | -- |
| Angle offset | +90 degrees (Fabric.js measures from 12 o'clock, atan2 from 3 o'clock) | -- |

During rotate: update `angle` property. Commit on `pointerup`.

### Double-Click State

| Element | Visual | Cursor |
|---------|--------|--------|
| Double-clicked annotation | Fires `onRequestEditMode(annotationId, pageNumber)` callback | -- |
| Phase 9 scope | Only fires the signal. Canvas mounting is Phase 10/11. | -- |

## Constant-Size Handle Strategy

All handles must appear the same physical pixel size regardless of zoom level. The SVG `viewBox` causes all content to scale with zoom. Handles must counteract this scaling.

**Approach:** Inverse-scale transform.

```
inverseScale = 1 / currentScale
currentScale = svgElement.clientWidth / viewBoxWidth
```

Every handle dimension (radius, width, height, stroke-width, dash-array, shadow offsets, rotation handle offset) is multiplied by `inverseScale` in the SVG attributes.

`currentScale` is computed once per render (or on container resize) from the SVG element's measured dimensions vs. its viewBox. It does NOT read from the Syncfusion zoom percentage (per CLAUDE.md: must use container-aware measurement).

## Cursor Contract

Cursors must accurately communicate what interaction is available. These are the exact CSS cursor values for each handle and state.

| Target | State | Cursor Value |
|--------|-------|-------------|
| Annotation body | Idle | `default` |
| Annotation body | Hovered | `pointer` |
| Annotation body | Selected (not dragging) | `move` |
| Annotation body | Dragging | `grabbing` |
| Corner handle tl | Default | `nwse-resize` |
| Corner handle tr | Default | `nesw-resize` |
| Corner handle bl | Default | `nesw-resize` |
| Corner handle br | Default | `nwse-resize` |
| Mid-edge handle mt | Default | `ns-resize` |
| Mid-edge handle mb | Default | `ns-resize` |
| Mid-edge handle ml | Default | `ew-resize` |
| Mid-edge handle mr | Default | `ew-resize` |
| Rotation handle mtr | Default | `crosshair` |
| SVG background | Default | `default` |

**Note on rotated annotations:** When an annotation is rotated, the resize cursors should rotate accordingly. For example, if an annotation is rotated 45 degrees, the `tl` corner cursor should be `ns-resize` instead of `nwse-resize`. Cursor rotation follows the formula: `cursorIndex = Math.round(((angle % 360) + 360) % 360 / 45) % 8` mapping to the 8-direction cursor cycle.

## Z-Order Contract

| Layer | Z-Index (within SVG) | Content |
|-------|---------------------|---------|
| Bottom | Render order 1 | Annotation SVG elements (paths, rects, ellipses, etc.) from Phase 8 |
| Middle | Render order 2 | Hover outline (shown on pointer hover, behind handles) |
| Top | Render order 3 | Selection overlay: bounding box + handles + rotation handle |

Within the annotation layer, z-order follows the `objects[]` array index -- later items render on top. Hit-testing uses topmost-wins: when annotations overlap, the one rendered last (highest array index) receives the click.

## Accessibility Notes

- All interactive SVG elements must have `role="button"` and `aria-label` attributes describing the control (e.g., `aria-label="Resize top-left corner"`).
- Keyboard interaction (Tab to select, arrow keys to move) is deferred to ADVN-01 (future milestone). Phase 9 is pointer-only.
- Selection state changes should be announced via `aria-live="polite"` region if screen reader support is required (implementation detail, not a Phase 9 gate).
