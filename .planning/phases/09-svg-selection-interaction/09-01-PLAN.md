Create two new utility modules that provide the math foundation for all SVG interaction.

**File 1: `src/utils/svgTransformMath.js`**

Export the following functions:

1. `screenToSVG(svgElement, clientX, clientY)` — Converts DOM clientX/clientY to SVG viewBox coordinates using `new DOMPoint(clientX, clientY).matrixTransform(svgElement.getScreenCTM().inverse())`. Returns `{ x, y }`. If `getScreenCTM()` returns null, return `{ x: 0, y: 0 }` as fallback.

2. `normalizeAngle(radians)` — Converts atan2 radians to Fabric.js degrees (0-360). Formula: `((radians * 180 / Math.PI) + 90 + 360) % 360`. The +90 adjusts from atan2's 3-o'clock origin to Fabric.js's 12-o'clock origin.

3. `constrainToPage(left, top, width, height, pageWidth, pageHeight)` — Clamps annotation position so it stays within page bounds (0,0 to pageWidth,pageHeight). Returns `{ left: clampedLeft, top: clampedTop }`. Clamp left to `[0, pageWidth - width]`, top to `[0, pageHeight - height]`.

4. `getInverseScale(svgElement, viewBoxWidth)` — Computes `1 / (svgElement.clientWidth / viewBoxWidth)`. This is the inverse scale factor needed to keep handles constant pixel size. If `svgElement.clientWidth` is 0, return 1.

5. `getCursorForHandle(handleId, angleDegrees)` — Returns the CSS cursor string for a resize handle, accounting for annotation rotation. The 8 cursors cycle: `['nwse-resize', 'ns-resize', 'nesw-resize', 'ew-resize', 'nwse-resize', 'ns-resize', 'nesw-resize', 'ew-resize']`. Base indices: tl=0, mt=1, tr=2, mr=3, br=4, mb=5, bl=6, ml=7. Rotation offset: `Math.round(((angleDegrees % 360 + 360) % 360) / 45) % 8`. Return cursor at `(baseIndex + rotationOffset) % 8`. For `mtr`, always return `'crosshair'`.

**File 2: `src/utils/svgBoundingBox.js`**

Export the following functions:

1. `getAnnotationBBox(obj)` — Computes bounding box from a Fabric.js JSON object. Logic by type:
   - **Path**: `left = obj.left ?? 0`, `top = obj.top ?? 0`, `width = (obj.width ?? 0) * Math.abs(obj.scaleX ?? 1)`, `height = (obj.height ?? 0) * Math.abs(obj.scaleY ?? 1)`, `angle = obj.angle ?? 0`. For paths, the visual position in the SVG includes the pathOffset transform, but for selection/drag purposes, `left`/`top` is the correct anchor point.
   - **Rect**: `left = obj.left ?? 0`, `top = obj.top ?? 0`, `width = Math.abs((obj.width ?? 0) * (obj.scaleX ?? 1))`, `height = Math.abs((obj.height ?? 0) * (obj.scaleY ?? 1))`, `angle = obj.angle ?? 0`.
   - **Line**: Compute from endpoints: `x1 = (obj.left ?? 0) + (obj.x1 ?? 0)`, `y1 = (obj.top ?? 0) + (obj.y1 ?? 0)`, etc. BBox = `{ left: min(x1,x2), top: min(y1,y2), width: abs(x2-x1), height: abs(y2-y1), angle: 0 }`. If width or height is 0, use a minimum of 10 for each to ensure hittable area.
   - **Arrow (group)**: Same as line, computed from group's line child coordinates offset by group `left`/`top`.
   - **Ellipse/Circle**: `left = obj.left ?? 0`, `top = obj.top ?? 0`. For circle: `width = height = (obj.radius ?? 0) * 2 * Math.abs(obj.scaleX ?? 1)`. For ellipse: `width = (obj.rx ?? 0) * 2 * Math.abs(obj.scaleX ?? 1)`, `height = (obj.ry ?? 0) * 2 * Math.abs(obj.scaleY ?? 1)`.
   - **Text**: `left = obj.left ?? 0`, `top = obj.top ?? 0`, `width = Math.abs((obj.width ?? 100) * (obj.scaleX ?? 1))`, `height = Math.abs((obj.height ?? 30) * (obj.scaleY ?? 1))`, `angle = obj.angle ?? 0`.
   - Returns `{ left, top, width, height, angle }`.

2. `getGroupBBox(bboxes)` — Computes the union bounding box of an array of `{ left, top, width, height }` objects. Returns `{ left: min(lefts), top: min(tops), width: maxRight - minLeft, height: maxBottom - minTop, angle: 0 }`. Used for multi-select group bounding box (Plan 03).

3. `getHandlePositions(bbox, padding)` — Given a bbox `{ left, top, width, height }` and padding (default 6, matching `fabricCustomization.js` padding: 6), returns the 9 handle positions:
   ```
   {
     tl: { x: left - padding, y: top - padding },
     tr: { x: left + width + padding, y: top - padding },
     bl: { x: left - padding, y: top + height + padding },
     br: { x: left + width + padding, y: top + height + padding },
     mt: { x: left + width/2, y: top - padding },
     mb: { x: left + width/2, y: top + height + padding },
     ml: { x: left - padding, y: top + height/2 },
     mr: { x: left + width + padding, y: top + height/2 },
     mtr: { x: left + width/2, y: top - padding - 40 }  // 40px above top, matching fabricCustomization.js offsetY: -40
   }
   ```

**Implementation details:**

1. **State:** Use `useState` for `selectedIds` (Set<number>), `hoveredId` (number|null). Use `useRef` for `dragStateRef` (mutable during drag), `interactionStateRef`.

2. **inverseScale:** Use `useState` initialized to 1. Add a `useEffect` that creates a `ResizeObserver` on `svgRef.current` to recompute `1 / (svgElement.clientWidth / pageWidth)` whenever the container resizes. Clean up observer on unmount. This is container-aware per CLAUDE.md requirements (must NOT compute from zoom percentage).

3. **handleAnnotationPointerDown(e, index):**
   - `e.stopPropagation()` to prevent SVG background handler from deselecting.
   - If shift key (`e.shiftKey`): toggle annotation in `selectedIds` (add if not present, remove if present). This supports INTR-07 shift-click (Plan 03 details).
   - If not shift: if annotation already selected, do nothing (allows subsequent drag). If not selected, `selectAnnotation(index, false)` (replaces selection).
   - NOTE: Do NOT call `e.target.setPointerCapture` here. That is Plan 02's job for drag operations. This task only handles click-to-select.

4. **handleAnnotationPointerEnter(e, index):** Set `hoveredId` to index.

5. **handleAnnotationPointerLeave(e, index):** Set `hoveredId` to null (only if current `hoveredId` matches index, to prevent race conditions).

6. **handleAnnotationDoubleClick(e, index):** Call `onRequestEditMode(index, annotations.objects[index]?.type)` if provided. `e.stopPropagation()`.

7. **handleSvgPointerDown(e):** If `e.target` is the `<svg>` element itself (not a child), call `deselectAll()`. Check via `e.target === svgRef.current`.

8. **handleHandlePointerDown(e, handleId):** Stub function that does nothing in this plan. Plan 02 will add drag/resize/rotate logic.

9. **selectAnnotation(index, addToSelection):** If `addToSelection`, add index to selectedIds set. Otherwise, create new set with just index.

10. **deselectAll():** Set `selectedIds` to empty set, set `hoveredId` to null.

11. **isSelected(index):** Return `selectedIds.has(index)`.

12. Clear selection when `annotations` prop changes (new page loaded or external edit). Use a `useEffect` that runs when `annotations` identity changes — call `deselectAll()`.
