**Part A: Multi-select enhancements in `useSVGInteraction`**

1. **Group drag (move multiple selected annotations together):**

   Modify `handleAnnotationPointerDown` — when starting a drag with multiple annotations selected (`selectedIds.size > 1`), record ALL selected annotations' original positions:
   ```js
   if (selectedIds.size > 1 && isSelected(index)) {
     // Group drag — record originals for ALL selected annotations
     const originals = {};
     for (const selIdx of selectedIds) {
       const selObj = annotations?.objects?.[selIdx];
       if (selObj) {
         originals[selIdx] = {
           left: selObj.left ?? 0,
           top: selObj.top ?? 0,
         };
       }
     }
     dragStateRef.current = {
       active: true,
       mode: 'group-move',
       handleId: null,
       startSVGPoint: svgPoint,
       originalProps: null,
       annotationIndex: index,
       ctmInverse,
       groupOriginals: originals,
     };
   }
   ```

   CRITICAL per RESEARCH.md Pitfall 6: On each move frame, compute position as `original + totalDelta` (not `current + frameDelta`). This prevents floating-point drift that causes annotations to spread apart.

2. **Add group-move handling to `handlePointerMove`:**
   ```js
   if (ds.mode === 'group-move') {
     const dx = svgPoint.x - ds.startSVGPoint.x;
     const dy = svgPoint.y - ds.startSVGPoint.y;
     setVisualTransform({
       id: 'group', // special sentinel for group drag
       dx, dy,
       affectedIds: new Set(Object.keys(ds.groupOriginals).map(Number)),
     });
     setInteractionState('dragging');
   }
   ```

3. **Add group-move handling to `handlePointerUp`:**
   ```js
   if (ds.mode === 'group-move' && ds.groupOriginals) {
     const dx = svgPoint.x - ds.startSVGPoint.x;
     const dy = svgPoint.y - ds.startSVGPoint.y;

     if (Math.abs(dx) > 2 || Math.abs(dy) > 2) {
       const updatedAnnotations = JSON.parse(JSON.stringify(annotations));

       for (const [idxStr, orig] of Object.entries(ds.groupOriginals)) {
         const idx = Number(idxStr);
         const obj = updatedAnnotations.objects[idx];
         if (!obj) continue;
         const bbox = getAnnotationBBox(obj);
         const constrained = constrainToPage(
           orig.left + dx, orig.top + dy,
           bbox.width, bbox.height, pageWidth, pageHeight
         );
         obj.left = constrained.left;
         obj.top = constrained.top;
       }

       onSaveAnnotations(updatedAnnotations, {
         source: 'object:modified',
         action: 'group-move',
         checkpointPolicy: 'normal',
       });
     }
   }
   ```

4. **Group delete function:**
   Add a `deleteSelected` function to the hook:
   ```js
   const deleteSelected = useCallback(() => {
     if (selectedIds.size === 0) return;

     const updatedAnnotations = JSON.parse(JSON.stringify(annotations));
     // Filter out selected indices (iterate in reverse order to preserve indices)
     const indicesToDelete = Array.from(selectedIds).sort((a, b) => b - a);
     for (const idx of indicesToDelete) {
       updatedAnnotations.objects.splice(idx, 1);
     }

     onSaveAnnotations(updatedAnnotations, {
       source: 'object:modified',
       action: 'delete',
       checkpointPolicy: 'normal',
     });

     deselectAll();
   }, [selectedIds, annotations, onSaveAnnotations, deselectAll]);
   ```

   Return `deleteSelected` from the hook.
