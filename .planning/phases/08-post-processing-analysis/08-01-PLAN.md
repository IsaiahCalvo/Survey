state.jsonl entry schema:
```json
{
  "sessionMs": 14170.7,

  "signals": {"pdfLoaded": true, "zoomSettled": true, "domSettled": true, "annotationsMounted": true}
}
```

performance.jsonl entry schemas:
```json
// CDP metrics type
{ "sessionMs": 14156, "type": "cdp", "metrics": { "LayoutCount": 4, "RecalcStyleCount": 58, "TaskDuration": 0.247, ... } }
// Performance mark type
{ "sessionMs": 10895, "type": "mark", "name": "pal_mount", "detail": { "page": 5 } }
```

console.jsonl entry schema:
```json
{ "sessionMs": 12345, "level": "error", "text": "Error message text", "location": {"url": "...", "lineNumber": 100}, "stackTrace": "..." }
```

manifest.json relevant fields:
```json
{ "scenario": "zoom-flicker", "result": "pass", "captureStartMs": 13474.3, "startTime": "2026-03-13T04:07:42.432Z", "endTime": "2026-03-13T04:07:46.901Z", "criteriaResults": { "canvasContainersPresent": {"pass": true, "value": 7}, "noConsoleErrors": {"pass": true, "errorCount": 0} } }
```

Screenshot filename convention:
```
step-NN_MMMMMms_timing-description.png
Example: step-01_14789ms_after-zoom-100pct.png
```

Performance mark names (from source code):
- pal_mount { page }, pal_unmount { page }
- fabric_renderStart { page, source?, scale? }, fabric_renderEnd { page, source?, scale? }
- zoom_start { scale, targetScale?, source }, zoom_end { source }
- portal_freeze { reason, source }, portal_unfreeze { reason }
- pdf_loaded { pageCount, currentPage }

CRITICAL: dom_pageAdded and dom_pageRemoved are NOT performance marks. They are DOM mutation records in state.jsonl mutations array with type: 'added'|'removed'.

  <action>
    1. Create `debug/lib/anomaly-detector.mjs`:
       - Export `detectAnomalies(timeline, manifest)` function
       - The timeline parameter is the merged array from mergeTimeline() (entries tagged with _source, _index)
       - The manifest parameter provides scenario metadata

       Internal helpers:
       - `parseScreenshotName(filename)`: Extract step, sessionMs, timing, description from `step-NN_MMMMMms_timing-description.png` pattern
       - `findNearestScreenshot(sessionMs, screenshots)`: Return filename of screenshot closest to given sessionMs
       - `buildPageEventChains(timeline)`: Reconstruct per-page event chains by correlating performance marks (pal_mount, pal_unmount, fabric_renderEnd from performance entries where _source='performance' and type='mark') with DOM mutations (from state entries where _source='state', scanning mutations array for type='added'|'removed'). Sort each page chain by sessionMs.

       Four detection rules per CONTEXT.md locked decisions:

       a) **Canvas container drop** -- Scan state entries (_source='state'). If canvasContainerCount === 0, emit critical anomaly. refs.stateIndex = entry._index.

       b) **Freeze overhang** -- Scan consecutive state entry pairs. If entry N has freezeState.scaleConfirmPending===true OR freezeState.zoomOverlayTransformActive===true, and the gap to entry N+1 exceeds 3000ms, emit critical anomaly. refs.stateIndex = entry._index.

       c) **Scale divergence** -- Scan consecutive state entry pairs. If entry N has renderedScale !== targetScale (and both are non-null), and the gap to entry N+1 exceeds 3000ms, emit warning anomaly. refs.stateIndex = entry._index.

       d) **Race condition** -- Use buildPageEventChains(). For each page, find dom_pageAdded events followed by pal_mount events. Calculate delta. If delta > 100ms: warning. If delta > 100ms AND a screenshot sessionMs falls within [dom_pageAdded.sessionMs, pal_mount.sessionMs]: critical. If delta 50-100ms: info. Below 50ms: skip.

       Parse screenshot filenames from manifest.artifacts (type='screenshot') for cross-referencing.
       Sort all anomalies by sessionMs before returning.
