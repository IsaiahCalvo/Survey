Create `src/components/FabricEditCanvas.jsx` -- a unified edit Canvas component with three modes controlled by an `editType` prop: `'text'`, `'shape'`, and `'callout'`.

**Component signature:**
```jsx
const FabricEditCanvas = memo(({
  pageNumber,
  pageWidth,
  pageHeight,
  editType,            // 'text' | 'shape' | 'callout'
  annotationData,      // Fabric.js JSON object for the annotation being edited
  annotationIndex,     // index in annotations.objects array
  annotations,         // full page annotations JSON (for callout: load all; for text/shape: single annotation)
  onEditCommit,        // (updatedAnnotationsJSON) => void
  onEditCancel,        // () => void
  strokeColor,         // current stroke color (for new text creation)
  zoomGeneration,      // zoom signal from App.jsx
  viewerScale,         // syncfusionViewerScale for callout radius correction
  isNewText,           // true when text tool click-to-place creates new annotation
  clickPosition,       // { x, y } in page coordinates for new text placement
}) => { ... })
```

**Architecture (follow FabricDrawingCanvas/FabricEraserCanvas patterns exactly):**

1. **Refs:** `canvasElRef`, `containerRef`, `onBeforeDisposeRef`, `fabricRef` (from useFabricCanvas), `mountedRef`, `annotationsRef`, `editTypeRef`, `onEditCommitRef`, `onEditCancelRef`, `cursorPositionRef` (for text zoom restore), `originalAnnotationRef` (for Escape cancel), `bboxOriginRef` (for coordinate mapping).

2. **Canvas lifecycle:** Use `useFabricCanvas({ canvasElRef, options: { selection: editType !== 'text', renderOnAddRemove: false, backgroundColor: 'transparent' }, onBeforeDisposeRef })`. Set `isDrawingMode: false` (editing, not drawing).

3. **Container sizing (bbox mode for text/shape):**
   Per UI-SPEC Canvas Container Sizing Contract:
   ```
   position: 'absolute',
   left: (annotationData.left - BBOX_PADDING) * effectiveScale,
   top: (annotationData.top - BBOX_PADDING) * effectiveScale,
   width: (annotationData.width * (annotationData.scaleX || 1) + BBOX_PADDING * 2) * effectiveScale,
   height: (annotationData.height * (annotationData.scaleY || 1) + BBOX_PADDING * 2) * effectiveScale,
   zIndex: 101,
   pointerEvents: 'auto',
   border: '1px solid rgba(74, 144, 226, 0.4)',
   borderRadius: '2px',
   ```
   Where `BBOX_PADDING = 20` and `effectiveScale = containerRef.current.parentElement.offsetWidth / pageWidth` (measure from parent portal container, same as FabricDrawingCanvas).

4. **Container sizing (full-page mode for callout):**
   ```
   position: 'absolute',
   left: 0, top: 0,
   width: containerEl.offsetWidth,
   height: containerEl.offsetHeight,
   zIndex: 101,
   pointerEvents: 'auto',
   ```

5. **Canvas init effect (runs once after mount):**
   - Wait for fabricRef.current to be available
   - Set `canvas.setZoom(effectiveScale)` for container-aware sizing
   - Set `canvas.setDimensions({ width: containerWidth, height: containerHeight })`
   - Branch by editType:

   **Text mode:**
   - If `isNewText`: create new `fabric.IText('')` at `{ left: BBOX_PADDING, top: BBOX_PADDING }` with font from strokeColor or default (`fontFamily: '-apple-system, BlinkMacSystemFont, "SF Pro Display", "Helvetica Neue", Arial, sans-serif'`, `fontSize: 16`, `fill: strokeColor || '#000000'`)
   - If editing existing: `fabric.util.enlivenObjects([annotationData], (objects) => { ... })`, reposition to `{ left: BBOX_PADDING, top: BBOX_PADDING }`, store original left/top in `bboxOriginRef.current = { left: annotationData.left, top: annotationData.top }`
   - Store deep copy of original annotation in `originalAnnotationRef.current = JSON.parse(JSON.stringify(annotationData))`
   - `canvas.add(textObj)`, `canvas.setActiveObject(textObj)`, `textObj.enterEditing()`, `textObj.selectAll()`
   - Listen for `text:editing:exited` event -> call `commitAndClose()`

   **Shape mode:**
   - `fabric.util.enlivenObjects([annotationData], (objects) => { ... })`
   - Reposition to `{ left: BBOX_PADDING, top: BBOX_PADDING }`
   - Store `bboxOriginRef.current`
   - `obj.set({ selectable: true, evented: true, hasControls: true, hasBorders: true })`
   - `canvas.add(obj)`, `canvas.setActiveObject(obj)`, `canvas.renderAll()`
   - Store `originalAnnotationRef.current`

   **Callout mode:**
   - Load ALL annotations via `fabric.util.enlivenObjects(annotations.objects, ...)` (same as FabricEraserCanvas pattern)
   - All objects `selectable: false, evented: false` EXCEPT the target annotation at `annotationIndex`
   - Target object: `selectable: true, evented: true, hasControls: true`
   - `canvas.setActiveObject(targetObj)`, `canvas.renderAll()`
   - Store `originalAnnotationRef.current`
   - No bboxOrigin mapping needed (full-page Canvas, coordinates are already absolute)

6. **Commit logic (`commitAndClose` function):**
   - For text: `if (textObj.isEditing) textObj.exitEditing()`
   - Serialize active object: `const json = activeObj.toJSON(CUSTOM_PROPS)`
   - For bbox mode (text/shape): reverse coordinate offset: `json.left = bboxOriginRef.current.left + (json.left - BBOX_PADDING); json.top = bboxOriginRef.current.top + (json.top - BBOX_PADDING);`
   - For new text: if text is empty string, call `onEditCancel()` instead (discard empty)
   - Build updated annotations: deep clone `annotationsRef.current`, replace `objects[annotationIndex]` with json (or append for new text)
   - Call `onEditCommitRef.current(updatedAnnotations)`

7. **Cancel logic (`cancelAndClose` function):**
   - For text: `if (textObj.isEditing) textObj.exitEditing()`
   - Call `onEditCancelRef.current()` (App.jsx reverts to pre-edit state via original annotations, no data mutation needed)

8. **Click-outside detection:**
   - Add `mousedown` listener on `document` in a useEffect
   - Check if click target is inside `containerRef.current` or inside mini-toolbar
   - If outside: call `commitAndClose()`
   - Cleanup listener on unmount

9. **Escape key handler:**
   - Add `keydown` listener on `document` in a useEffect
   - If `e.key === 'Escape'`: call `cancelAndClose()`

10. **Zoom handling (zoomGeneration useEffect):**
    - Watch `zoomGeneration` prop
    - If changed from initial: store cursor position (`cursorPositionRef.current = activeObj?.selectionStart`), call `commitAndClose()` which auto-commits
    - The Canvas key in App.jsx includes `zoomGeneration`, so React unmounts and remounts FabricEditCanvas at new dimensions after zoom settle (same pattern as FabricDrawingCanvas)

11. **onBeforeDispose callback:**
    - Set `onBeforeDisposeRef.current = (canvas) => { ... }`
    - If text is editing: `exitEditing()` on active object
    - Commit current state via `commitAndClose()` (auto-save on unmount, matching EDIT-09 pattern)
    - `flushSync(() => { onEditCommitRef.current(updatedAnnotations) })` for synchronous SVG re-render before Canvas DOM removal (Phase 10 pattern)

12. **Text auto-expand:**
    - Listen for `object:modified` on canvas
    - If text object dimensions exceed bbox Canvas dimensions, update container style width/height to accommodate (grow right and down, left/top stay fixed)
    - Maximum: full page dimensions

13. **Mini-toolbar for shapes (rendered as sibling div above Canvas container):**
    Per UI-SPEC Mini-Toolbar spec:
    - Only rendered when `editType === 'shape'`
    - Positioned 8px above bbox Canvas top edge; if insufficient space above, 8px below bottom edge
    - Layout: `Fill: [swatch] | Stroke: [swatch] | Width: [+-]`
    - Background: `#2D2D2D`, border: `1px solid #3A3A3A`, border-radius: `6px`, shadow: `0 4px 12px rgba(0,0,0,0.3)`
    - Size: auto width (min 240px, max 360px), height 36px
    - Fill swatch: 16x16px colored square showing current `obj.fill`, click opens color picker
    - Stroke swatch: 16x16px colored square showing current `obj.stroke`, click opens color picker
    - Width stepper: +/- buttons with numeric readout (e.g. "3px"), range 1-20, step 1
    - Labels: 12px font, weight 500, `#FFFFFF`; values: 12px, weight 400
    - Separator: vertical 1px `#3A3A3A` line, 20px tall
    - Color picker: reuse existing CompactColorPicker component if available, otherwise simple preset color grid
    - When user changes fill/stroke/width, immediately update the Fabric.js object (`obj.set({ fill: newColor })`, `canvas.renderAll()`)
