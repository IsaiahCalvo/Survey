### Bug: New text cursor drift (text outpaces cursor)

**What we know:**
- Imported Syncfusion annotation (fontFamily="Helv", fontSize=16, width=100) has ZERO cursor drift when edited through FabricEditCanvas
- Our new text annotations (fontFamily=system font stack, fontSize=16, width=160) have progressive cursor drift
- Both now use identical code patterns: zoom=es, page-space coords, same cache clearing, same render order
- The remaining difference is **fontFamily**: "Helv" vs "-apple-system, BlinkMacSystemFont, 'SF Pro Display', 'Helvetica Neue', Arial, sans-serif"

**Hypotheses (prioritized):**
1. **Font family difference** — "Helv" (Helvetica) has very consistent character metrics in Canvas 2D. The multi-fallback system font stack may cause Fabric.js's character measurement at CACHE_FONT_SIZE=400px to scale differently than the actual rendered characters. Test: try creating new text with fontFamily="Helv" or "Helvetica" to see if drift disappears.
2. **splitByGrapheme behavior with system fonts** — splitByGrapheme measures each character individually. System fonts with font substitution/fallback may have inconsistent individual vs sequential measurements. Test: try splitByGrapheme=false.
3. **Fabric.js Textbox vs IText cursor calculation** — The existing annotation goes through `enlivenObjects` then gets reconstructed as Textbox. There may be subtle initialization differences vs creating a fresh Textbox directly.
4. **Consider FabricTextCanvas.jsx (native textarea)** — Already built, specifically designed for this. Would eliminate Canvas 2D text measurement entirely. User was resistant to "building from scratch" but this already exists.

**Next steps:**
1. Quick test: change DEFAULT_FONT_FAMILY to "Helvetica" temporarily — if drift disappears, font is the issue
2. If font is the issue: either use a simpler font stack or investigate Fabric.js font cache behavior with multi-font stacks
3. If font is NOT the issue: deeper comparison of enlivenObjects initialization vs direct constructor
4. Nuclear option: revive FabricTextCanvas.jsx native textarea approach
