### This session fixes (all uncommitted on Layer-Revamp):

1. **Rotated text/shape edit — CSS rotation on container div**
   - `src/components/FabricEditCanvas.jsx`: Container div gets `transform: rotate(angle)` with `transformOrigin` at annotation center when editing rotated annotations
   - Object inside canvas has `angle: 0` (stripped for easy editing — cursor, selection, wrapping all work normally)
   - On commit, original angle restored from `bboxOriginRef.current.angle`
   - Applied to both text and shape loading paths
   - Post-zoom container style update also preserves rotation
   - Zoom transform composes rotation with scale (`rotate(Xdeg) scale(Y)`)

2. **Text flash to top-left on double-click — FIXED**
   - Root cause: `new fabric.Textbox(text, { ...rest })` included original page-space `left`/`top` from annotation data. Object briefly existed at wrong position before `set({ left: BBOX_PADDING })`.
   - Fix: Destructure `left`, `top`, `angle` out of `rest` and set `left: BBOX_PADDING, top: BBOX_PADDING, angle: 0` directly in constructor.
   - Also reordered canvas resize to happen BEFORE `renderAll()` and `enterEditing()`.

3. **Container visibility timing — prevents first-frame flash**
   - Initial `containerStyle` state starts with `{ visibility: 'hidden' }`
   - Container style useEffect applies style directly to DOM synchronously (not just via React state) to prevent one-frame delay where container shows at previous position
   - `container.style.visibility = 'visible'` set only after all position/rotation properties are applied

4. **Debug logging added (temporary)**
   - 8+ `[EditCanvas]` tagged console.log statements tracing the full text edit mount sequence
   - Logs: annotation data, enlivenObjects result, Textbox constructor values, canvas sizing, container style, renderAll/enterEditing timing, hiddenTextarea state
   - These should be REMOVED once the rotation jump bug is confirmed fixed

- Canvas resize moved before first renderAll to prevent size mismatch flash

For non-rotated text this is invisible; for rotated text the old vs new rotation creates a visible jump. Fix: apply style directly to DOM in the useEffect.
