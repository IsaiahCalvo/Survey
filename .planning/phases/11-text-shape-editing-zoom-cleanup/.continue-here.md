<context>
The core challenge this session: Fabric.js Canvas text rendering uses different metrics than CSS/browser text rendering. When text is edited in Fabric.js at effectiveScale-multiplied coordinates and then committed back to page-space for SVG display, any rounding or metric differences cause text to wrap differently. The fixes this session addressed:
1. fontSize double-rounding (Math.round removed)
2. CSS border-box reducing content width (border moved to SVG rect, border-box removed)
3. Missing height conversion in commit path (json.height / es added)

Key files modified:
- `src/utils/svgAnnotationRenderers.jsx` — renderText: SVG rect border, descender buffer, content-box padding
- `src/utils/svgBoundingBox.js` — getTextBBox: descender buffer
- `src/components/FabricEditCanvas.jsx` — commit path: height conversion, fontSize no-round, splitByGrapheme always true
- `src/components/SVGAnnotationLayer.jsx` — Delete key handler, removed expandTextBBox
- `src/App.jsx` — Text tool overlays: click-on-existing-text detection (all 3 scroll modes)
</context>
