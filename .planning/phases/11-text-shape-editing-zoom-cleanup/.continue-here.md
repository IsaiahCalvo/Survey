<context>
The zoom-during-editing problem was fundamentally about React state updates being async/batched.
When ResizeObserver fired during zoom, `setContainerStyle` (position) and `setZoomTransformStyle` (CSS scale)
were batched React updates that could paint on different frames — causing the container to briefly appear
at the new position with old scale or vice versa. Direct DOM manipulation solves this because both
style changes are applied synchronously in the same ResizeObserver callback, before the browser paints.

The text will appear slightly blurry during zoom (CSS-scaled bitmap) but stays visible and correctly
positioned. It sharpens at settle when the canvas is actually resized. This is acceptable UX.
</context>
