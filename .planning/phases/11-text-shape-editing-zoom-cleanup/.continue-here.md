### Callout UX fixes still needed (from combined-tools analysis):

#### Fix #4: Distance constraints on knee/arrowTip drag (HIGH PRIORITY)
**File:** `src/components/Callout/CalloutCanvas.jsx` lines 286-288
**Problem:** Knee and arrowTip can be dragged anywhere with zero constraints. Users can drag knee inside textbox or on top of arrowTip.
**Combined-tools behavior:** MIN_HANDLE_DISTANCE = 30px enforced between:
- Knee ↔ ArrowTip (push knee along angle away from arrow)
- Knee ↔ TextBox edge (push knee to nearest edge + 30px if inside)
- ArrowTip ↔ Knee (push tip along angle away from knee)
**Fix:** In `handleMouseMove`, add constraint logic for cases `'arrowTip'` and `'knee'` that enforces 30px minimum distances. Need to convert between percent and pixel space for distance calculations.

#### Fix #5: Resize handles jump on drag start (HIGH PRIORITY)
**File:** `src/components/Callout/CalloutCanvas.jsx` lines 303-356
**Problem:** Resize uses absolute mouse position vs initial textbox position. Mouse cursor isn't at exact corner when drag starts → visual jump on first frame.
**Combined-tools behavior:** Fabric.js handles this natively with internal offset tracking.
**Fix:** Capture initial mouse position at drag start in `cornerResizeInitialStateRef`. Calculate delta from initial mouse position, apply to initial dimensions. Don't use absolute mouse position.

#### Fix #6: No geometry recalculation during resize (MEDIUM)
**Problem:** Line connection points don't update during textbox resize. Combined-tools calls `calculateCalloutConnection()` on every scaling event.
**Fix:** During `textBoxCorner` drag, recalculate where line1 starts from textbox edge and update knee position via `calculateCalloutConnection()`.

#### Fix #7: Knee-inside-textbox emergency pop-out (MEDIUM)
**Problem:** If knee ends up inside textbox during any drag, no correction happens.
**Combined-tools behavior:** Detects knee inside box → finds nearest edge → pushes 30px outside.
**Fix:** Add inside-box detection in knee drag handler with pop-out logic.
