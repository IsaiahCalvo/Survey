### This session fixes (all uncommitted on Layer-Revamp):

1. **Rotation pivot point fix (renderText, renderRect, renderEllipse)**
   - `src/utils/svgAnnotationRenderers.jsx`: All SVG renderers now rotate around the CENTER of the object (matching Fabric.js behavior), not the top-left corner.
   - renderRect: `rotate(angle, left + effectiveWidth/2, top + effectiveHeight/2)`
   - renderEllipse: Added rotation support with `rotate(angle, cx, cy)`
   - renderText: `rotate(angle, left + effectiveWidth/2, top + effectiveHeight/2)`

2. **Hit rect + hover outline rotation**
   - `src/components/SVGAnnotationLayer.jsx`: Wrapped hit rect and hover outline in a `<g>` with matching rotation transform so they rotate with the annotation after commit.

3. **Delta rotation during active drag (double-rotation fix)**
   - `src/hooks/useSVGInteraction.js`: Added `deltaAngle = newAngle - originalAngle` to rotation visual transform. The wrapper `<g>` now applies only the delta during drag (annotation renderer already renders committed angle internally).
   - `src/components/SVGAnnotationLayer.jsx`: computedTransform for rotation uses `deltaAngle` instead of absolute `angle`.

4. **Highlight double-click guard (prevents stuck editing state)**
   - `src/App.jsx` (both render paths, lines ~24552 and ~24821): Added `if (annotationType === 'path' || annotationType === 'line') return;` guard in onRequestEditMode. Prevents highlights/pen strokes from entering edit mode (which caused infinite re-render loop and required app refresh).
