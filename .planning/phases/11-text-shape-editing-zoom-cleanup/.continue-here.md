### Text thickness (Bug 2): DOCUMENTED AS LIMITATION
Canvas 2D `fillText()` on macOS uses Core Graphics font rendering which produces slightly bolder glyphs than the browser's HTML text engine (SVG foreignObject). No CSS property or Fabric.js setting can make them match exactly. The `-webkit-font-smoothing: antialiased` change reduces the gap slightly. User confirmed this is noticeable "in some text boxes" — varies by font size and weight.
