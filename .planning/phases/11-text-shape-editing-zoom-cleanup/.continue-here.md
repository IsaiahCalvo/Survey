### CRITICAL: Callout UX must match combined-tools reference app

The combined-tools app at ~/Desktop/combined-tools is the target UX. Key file: `src/components/FabricPDFCanvas.tsx` (4264 lines).

#### Current problems:
1. **Callouts only interactable via pan tool, not select tool** — The SVG layer's wrapper div controls pointer events based on `isInteractive` (select/text-select only). CalloutOverlay sits inside PAL which may be behind the SVG layer's pointer event blocking.
2. **Creation flow doesn't match** — Combined-tools: mousedown sets arrow tip, mousemove shows preview, mouseup places textbox. Current app: click creates at click point with no drag preview.
3. **No knee/arrowhead drag handles** — Combined-tools has 12×12 white/blue squares for knee and arrow tip that are independently draggable with 30px minimum distance constraints.
4. **No textbox resize via corner handles** — Combined-tools textBoxBg has corner resize handles (tl, tr, bl, br) with min 20px text width.
5. **No two-click text editing** — Combined-tools: first click selects, second click enters text edit mode with `enterEditing()` + `selectAll()`.
6. **Callout state resetting** — Logs show `setCallouts prev count: 0 → 1` repeating (should increment), suggesting stale closure in setCallouts.

#### Combined-tools callout data model:
```
{
  id: string (UUID),
  arrowTip: { x, y },          // Absolute world coords of arrow
  knee: { x, y },               // Absolute world coords of knee
  textBoxPosition: { x, y },    // Top-left corner of textbox
  textBoxWidth: number,          // 120px default
  textBoxHeight: number,         // 40px default
  text: string,
  style: { borderColor, lineThickness, fillColor, opacity, fontFamily, fontSize, fontColor, bold, italic },
  isSelected: boolean
}
```

#### Combined-tools creates 7 Fabric objects per callout:
- Line1 (textbox → knee), Line2 (knee → arrow), ArrowHead (Triangle)
- TextBoxBg (Rect with corner handles), Text (editable Textbox)
- ArrowTipHandle (12×12 Rect), KneeHandle (12×12 Rect)

#### Combined-tools geometry: `calculateCalloutConnection()`
- MIN_KNEE_TO_ARROW_DISTANCE = 15px
- MIN_KNEE_TO_BOX_EDGE_DISTANCE = 10px
- Handles knee-inside-textbox, knee-on-border, knee-stacked-with-arrow
- Returns: line1Start, line2Start, effectiveKnee, shouldHideLine1

#### Combined-tools event flow:
- Creation: mousedown (arrow tip) → mousemove (preview) → mouseup (place textbox, auto-select)
- Select: click on any callout part → selectedCalloutId set → handles shown
- Knee drag: constrained 30px from arrow AND 30px from textbox edge
- Arrow drag: constrained 30px from knee
- Textbox resize: corner handles, text reflows (doesn't scale), min 20px width
- Two-click edit: first click selects, wasSelectedRef tracks, second click enters editing
- Deselect: click empty canvas → handles hidden
