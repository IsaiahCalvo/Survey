### Bug 5: Text font size/weight mismatch — PENDING
Text appears larger/bolder in FabricEditCanvas edit mode vs SVG display. Container bbox is also larger in edit mode.
**Root cause:** effectiveScale multiplication on fontSize in Fabric.js canvas (`fontSize: Math.round(16 * es)`) vs CSS font rendering in SVG foreignObject (`fontSize: 16px` with SVG viewBox scaling). The rounding and different rendering engines produce different visual sizes.
**Fix approach:** Align FabricEditCanvas text rendering with SVG — likely adjust canvas zoom approach so Fabric.js renders at native font size rather than pre-multiplying by effectiveScale.
