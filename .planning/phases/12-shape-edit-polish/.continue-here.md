**Round 7 root cause (FOUND)**:
The wrapper div had `onMouseDown` and `onPointerDown` stopPropagation but NOT
`onMouseUp`, `onPointerUp`, or `onClick`. When the user clicked the pill, the
mousedown was correctly stopped — but the mouseup propagated up to the SVG
layer / overlay / app, where some handler caused focus loss as a side effect
on mouse RELEASE. User confirmed the symptom directly: "if I hold my mouse
down I can type, but releasing dismisses it."

**Round 7 fix**:
`src/components/RotationInputField.jsx` — added three more wrapper handlers:
  - `onMouseUp={(e) => e.stopPropagation()}`
  - `onPointerUp={(e) => e.stopPropagation()}`
  - `onClick={(e) => e.stopPropagation()}`

Stops the FULL click cycle (down → up → click) at the pill boundary so no
parent handler can interfere with focus on mouse release.
