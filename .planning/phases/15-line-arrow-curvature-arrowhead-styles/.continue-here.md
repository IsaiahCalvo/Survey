<decisions_made>
- Imported callout border color = AP-stream stroke (not `/C`) for callouts. Acrobat writes `/C` as the interior fill for FreeTextCallouts; the AP-stream `RG` stroke is the authoritative painted border.
- Appearance-stream parser honors `q`/`Q` state stack. Text-paint `0 G` inside `q … Q` was overwriting the outer stroke color; honoring the restore fixes border-color reads for nested paint blocks.
- Auto-grow stored callout height on import to fit wrapped content at the stored width. Acrobat sometimes saves a 1-line-tall rect for content that wraps to 2+ lines; growing on import keeps the stored box matching what Acrobat paints.
- Non-uniform aspect handled in the EDIT canvas via `setViewportTransform`, not by changing the preview SVG's `preserveAspectRatio`. Changing preview aspect would cascade into every annotation and Syncfusion positioning. Gate is `abs(Y-X) > 0.0005 && !pageSpaceModeRef.current`.
- Preview `padX` dropped to 0 to match Fabric's zero default. Any inset widened the preview vs the editor by `12 page px × scale` and produced the visible "grow on edit" the user flagged repeatedly.
- pdf.js rewrite-and-retry guard uses `__rewrittenForParse` on the file object, not a function-scoped flag. The effect re-runs with a fresh function on each file swap; the file-scoped flag survives.
- `fontKerning:none` + `textRendering:geometricPrecision` + `fontVariantLigatures:none` are kept on the preview div even though they did not fully close the cursor drift — they move the needle in the right direction and are cheap.
- Handoff now written as `.continue-here.md` (GSD pause-work) instead of `HANDOFF.md`, per user correction this turn.
</decisions_made>
