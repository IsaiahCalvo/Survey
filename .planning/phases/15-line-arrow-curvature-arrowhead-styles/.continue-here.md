**Fix 3 — "everything vanishes" layer-wide hide** (blocker for closing UAT #1):

Root cause: `src/App.jsx:26664`, `:27356`, `:27875` all apply
`visibility: (isEditMode && editingAnnotation?.editType === 'callout') ? 'hidden' : 'visible'`
to the SVG layer wrapper. Hides the ENTIRE SVG (all annotations, not just
the callout being edited). Intended to prevent the edited callout from
double-rendering (SVG chrome + Fabric edit canvas on top) but too broad.

Fix path (needs user waiver for App.jsx narrow-lane touch):

1. `src/App.jsx` × 3 sites (26664, 27356, 27875) — change
   `visibility: ...conditional...` → remove the conditional (default 'visible').
2. `src/App.jsx` × 3 SVGAnnotationLayer mount sites (~26688, ~27430, ~27946) —
   add prop `editingCalloutId={editingAnnotation?.editType === 'callout' ? editingAnnotation?.reactCalloutId : null}`.
3. `src/components/SVGAnnotationLayer.jsx` — accept the new prop; in
   `filteredCallouts` useMemo (~1149-1203), skip the callout whose id matches
   `editingCalloutId` (mirrors the text-annotation `hideForEdit` pattern at
   `:1331-1332`).

Total change: ~4 lines App.jsx + ~5 lines SVGAnnotationLayer.jsx. No logic
changes beyond "hide only the one callout being edited, not the whole layer."
