<decisions_made>

- **Banner dismiss does not stop retries** (decision): the 1Hz background drainQueue continues whether the banner is open, closed, or never shown. Closing the banner is purely a visual-mute. This matches Linear / Notion / Figma "graceful degradation" patterns.
- **Banner persists while quarantined entries exist** (decision): stuckCount drops to 0 once an entry hits 10 failed retries, so we now also include `quarantinedAnnoIds.length > 0` in the gate. Otherwise the banner would silently disappear even though the user's data is unsaved.
- **Test seam fires post-serialize** (decision): the failure injection is placed AFTER `serializeAnnotationsByPage` so the side-effect of stamping ids onto id-less fabric objects has already landed when the simulated failure happens. Matches production failure timing where Supabase rejects an already-serialized request.
- **Quarantined entries count as "unpushed" for focus-rehydrate skip** (decision): otherwise the focus-rehydrate replace would wipe quarantined data off the canvas.
- **Polish items deferred to next session** (decision): user paused at 43% context (per their display) to bank a clean handoff rather than grind through small UX work in a fatigued session.
