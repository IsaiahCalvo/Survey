<objective>
Eliminate the 3-second annotation flicker after zoom by neutralizing the confirm-pending canvas-hiding system (App.jsx) and simplifying PAL's scale useEffect (PageAnnotationLayer.jsx).

Purpose: The `beginSyncfusionScaleConfirmPending` system was designed for a frozen-to-live `layerScale` transition that Phase 3 already removed (line 24597 now reads `const layerScale = syncfusionViewerScale > 0 ? syncfusionViewerScale : 1` -- always live). This system currently HIDES live canvases for 3 seconds on every zoom settle, causing the flicker bug. By replacing all 4 `beginSyncfusionScaleConfirmPending` calls with direct `resetSyncfusionOverlayTransformStyles()` and then simplifying PAL's useEffect, annotations become crisp after zoom without any disappearance window.

Output: Modified `src/App.jsx` (4 confirm-pending calls replaced, `onScaleApplied` prop removed from PAL render, memo comparison updated) and modified `src/PageAnnotationLayer.jsx` (scale useEffect simplified, 3 dead props removed, 5 onScaleApplied call sites removed, 300ms timer removed, wrapper CSS transform logic removed).

The key insight is that `beginSyncfusionScaleConfirmPending` must be neutralized FIRST, before any PAL changes. All prior attempts removed `onScaleApplied` from PAL without addressing the App.jsx system that depends on it, causing 3-second canvas hiding.

The key structural change in the deferred resize path (when `inZoomModeRef.current` is true):

CURRENT CODE (lines 7847-7955): Sets up a 300ms `setTimeout(settleCallback, 300)` that contains the tiered redraw logic.

NEW CODE: Remove the setTimeout wrapper. Instead, use `isZoomingRef.current` as the guard. If `isZoomingRef.current` is true, store pending scale and return. If false, this is the settle signal -- execute the tiered redraw immediately (same `settleCallback` body, just without the setTimeout wrapper).

The settle signal flow is:
1. During zoom: `isInteracting` is true -> PAL defers (existing guard at line 7807)
2. Interaction finalizes -> `isInteracting` goes false -> useEffect re-fires
3. The `isZooming` prop (from `useZoomState`) may briefly be true -> defer
4. `isZooming` goes false -> useEffect re-fires -> executes tiered redraw

The existing `isInteracting` guard (line 7807) is the PRIMARY zoom debounce. It prevents PAL from doing expensive redraws during zoom because `isInteracting` stays true for the entire zoom interaction. The 300ms timer was a SECONDARY debounce that is no longer needed.
