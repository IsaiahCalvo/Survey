For each annotation object:

2. **Compute region overlay state for this page**:
   ```
   isOverlayEnabledForThisPage = false
   if (activeRegions !== null && selectedSpaceId && isRegionOverlayEnabled) {
     const space = spaces?.find(s => s.id === selectedSpaceId)
     if (space) {
       const page = space.assignedPages?.find(p => p.pageId === pageNumber)
       if (page) isOverlayEnabledForThisPage = isRegionOverlayEnabled(selectedSpaceId, pageNumber, page)
     }
   }
   hasActiveRegions = (activeRegions !== null && Array.isArray(activeRegions) && activeRegions.length > 0) && isOverlayEnabledForThisPage
   ```

3. **Per-object filtering**:
   - `isSurveyAnnotation = obj.moduleId !== null && obj.moduleId !== undefined`
   - `isScopedRegionAnnotation = obj.regionId !== null && obj.regionId !== undefined`
   - `derivedSpaceId = isScopedRegionAnnotation ? getSpaceIdForRegion(obj.regionId) : null`

4. **Space matching** (matchesSpace):
   - If `hasActiveRegions && !isScopedRegionAnnotation`: `matchesSpace = true` (background annotations pass space filter when regions active)
   - Else if `isScopedRegionAnnotation && derivedSpaceId !== null`: `matchesSpace = activeSpaceId !== null && derivedSpaceId === activeSpaceId`
   - Else: `matchesSpace = true`

5. **Survey visibility** (surveyAnnotationVisible):
   - If `isSurveyAnnotation`: `visible = showSurveyPanel && selectedModuleId !== null && obj.moduleId === selectedModuleId`
   - Else if `!isScopedRegionAnnotation`: `visible = !(showSurveyPanel && selectedModuleId !== null)`
   - Else (region-scoped): `visible = true` (controlled by scopedRegionAnnotationVisible)

6. **Scoped region visibility** (scopedRegionAnnotationVisible):
   - If `!isScopedRegionAnnotation`: `visible = true`
   - Else if `activeSpaceId === null`: `visible = false`
   - Else if `hasActiveRegions`: `visible = true`
   - Else if `activeRegionId !== null`: `visible = obj.regionId === activeRegionId`
   - Else: `visible = false`

7. **Background annotation visibility** (backgroundAnnotationVisible):
   - If `!isScopedRegionAnnotation && obj.regionId === null`:
     - If `selectedSpaceId !== null && getRegionLightbulbState`: `visible = getRegionLightbulbState(selectedSpaceId, pageNumber)`
     - Else: `visible = true`
   - Else: `visible = true`

8. **Final visibility**:
   ```
   isVisible = matchesSpace && surveyAnnotationVisible && scopedRegionAnnotationVisible && (isScopedRegionAnnotation ? true : backgroundAnnotationVisible)
   ```
