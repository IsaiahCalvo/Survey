# Phase 8 — UI Design Contract

> Visual and interaction contract for SVG annotation display layer. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase nature:** This phase renders annotation data as SVG elements overlaid on PDF pages. There are no traditional UI chrome elements (buttons, forms, cards, navigation). The "design contract" defines SVG rendering rules, color/stroke semantics, visual fidelity requirements, and developer-facing toggle UI.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (browser-native SVG + React) |
| Icon library | none (no icons in this phase) |
| Font | inherits from annotation data (Fabric.js JSON `fontFamily` property per annotation) |

**Rationale:** This phase adds zero new dependencies. All rendering uses browser-native SVG elements inside React components. No design system library is appropriate because this is not application chrome -- it is a data visualization layer.

---

## Spacing Scale

This phase does not introduce UI chrome with layout spacing. The only spacing-relevant values are SVG coordinate offsets derived from Fabric.js JSON data.

Declared values (multiples of 4, used only in the renderer toggle indicator):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Toggle indicator inner padding |
| sm | 8px | Toggle indicator margin from viewport edge |

Exceptions: All annotation positions are derived from Fabric.js JSON (`left`, `top`, `width`, `height`, `pathOffset`) in unscaled PDF page coordinates. These are data-driven, not design tokens.

## Typography

This phase has two typography contexts:

### 1. Annotation Text Rendering (data-driven, not tokenized)

Text annotations render with properties read directly from Fabric.js JSON. The SVG layer does NOT impose font choices -- it faithfully reproduces what the annotation data specifies.

| Property | Source | Fallback |
|----------|--------|----------|
| Font family | `obj.fontFamily` | `sans-serif` |
| Font size | `obj.fontSize` | `16px` |
| Font weight | `obj.fontWeight` | `400` (normal) |
| Line height | `obj.lineHeight` | `1.16` (Fabric.js default) |
| Text color | `obj.fill` | `#000000` |
| Text align | `obj.textAlign` | `left` |
| White space | -- | `pre-wrap` (always) |
| Word wrap | -- | `break-word` (always) |
| Overflow | -- | `hidden` (always) |

### 2. Renderer Toggle Indicator (developer-facing chrome)

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Toggle label | 12px | 600 (semibold) | 1.0 | `monospace` |

## Color

This phase does not define application-level 60/30/10 color split. All annotation colors come from Fabric.js JSON data. The contract defines:

### Annotation Color Semantics (data-driven)

| Property | Source | Fallback | Notes |
|----------|--------|----------|-------|
| Stroke color | `obj.stroke` | `#000000` | Lines, arrows, shape borders, pen strokes |
| Fill color | `obj.fill` | `transparent` | Shape fills, erased path fills, text color |
| Opacity | `obj.opacity` | `1.0` | Applied to entire annotation element |
| Highlight blend | `obj.globalCompositeOperation === 'multiply'` | -- | Triggers `mix-blend-mode: multiply` on element |
| Callout line color | `callout.style.lineColor` | `#4A90E2` | Callout connection lines |
| Callout fill | `callout.style.fillColor` | `rgba(255, 255, 255, 0.22)` | Callout text box background |

### SVG Layer Container

| Role | Value | Usage |
|------|-------|-------|
| SVG background | `transparent` | SVG container has no background -- PDF shows through |
| Pointer events | `none` | Display-only in Phase 8 -- no interaction |

### Renderer Toggle Indicator (developer-facing)

| Role | Value | Usage |
|------|-------|-------|
| SVG mode badge background | `#10B981` (green-500) | Indicates SVG renderer is active |
| SVG mode badge text | `#FFFFFF` | Label text on green badge |
| Canvas mode badge background | `#6366F1` (indigo-500) | Indicates Canvas renderer is active |
| Canvas mode badge text | `#FFFFFF` | Label text on indigo badge |

Accent reserved for: renderer toggle badge only (developer tool, not user-facing).

## SVG Rendering Contract

> This section replaces the standard "component inventory" for this phase. Each annotation type has a specific SVG rendering contract.

### Global SVG Root

```
<svg viewBox="0 0 {pageWidth} {pageHeight}" width="100%" height="100%"
     preserveAspectRatio="none"
     style="position: absolute; top: 0; left: 0; pointer-events: none; overflow: hidden;">
```

| Property | Value | Rationale |
|----------|-------|-----------|
| viewBox | `0 0 {pageWidth} {pageHeight}` | Unscaled PDF page dimensions (e.g., `0 0 612 792` for US Letter) |
| width / height | `100%` / `100%` | Fills overlay div which tracks Syncfusion page size |
| preserveAspectRatio | `none` | Container-aware sizing from v1.0 Phase 3 already handles aspect ratio; `none` ensures SVG stretches to match overlay div exactly (required for Electron zoom factor mismatch) |
| pointer-events | `none` | Display-only in Phase 8; interaction comes in Phase 9 |
| overflow | `hidden` | Clip annotations that extend past page bounds |

### Type 1: Pen Strokes

| Property | SVG Attribute | Value |
|----------|---------------|-------|
| Element | `<path>` | -- |
| Path data | `d` | `obj.path` segments joined: `seg.join(' ')` per segment, segments joined with space |
| Transform | `transform` | `translate({left}, {top}) rotate({angle}) scale({scaleX}, {scaleY}) translate({-pathOffset.x}, {-pathOffset.y})` |
| Stroke | `stroke` | `obj.stroke` or `#000000` |
| Stroke width | `stroke-width` | `obj.strokeWidth` or `1` |
| Fill | `fill` | `none` |
| Stroke linecap | `stroke-linecap` | `round` |
| Stroke linejoin | `stroke-linejoin` | `round` |
| Non-scaling stroke | `vector-effect` | `non-scaling-stroke` when `obj.strokeUniform === true` |
| Opacity | `opacity` | `obj.opacity` or `1` |

### Type 2: Highlighter Strokes

Same as pen strokes, plus:

| Property | SVG Attribute | Value |
|----------|---------------|-------|
| Detection | -- | `obj.globalCompositeOperation === 'multiply'` |
| Blend mode | `style.mixBlendMode` | `multiply` |
| Typical opacity | `opacity` | As stored in JSON (usually `0.3`-`0.5`) |

### Type 3: Erased Paths (boolean subtraction results)

| Property | SVG Attribute | Value |
|----------|---------------|-------|
| Detection | -- | `obj.strokeWidth === 0 && obj.fill && obj.fill !== 'transparent'` |
| Element | `<path>` | -- |
| Transform | `transform` | Same as pen strokes (includes pathOffset) |
| Stroke | `stroke` | `none` |
| Stroke width | `stroke-width` | `0` |
| Fill | `fill` | `obj.fill` (the original stroke color) |
| Fill rule | `fill-rule` | `evenodd` (for correct hole rendering) |

### Type 4: Lines

| Property | SVG Attribute | Value |
|----------|---------------|-------|
| Element | `<line>` | -- |
| Coordinates | `x1`, `y1`, `x2`, `y2` | Group `left`/`top` + child line offsets |
| Stroke | `stroke` | `obj.stroke` or `#000000` |
| Stroke width | `stroke-width` | `obj.strokeWidth` or `2` |
| Linecap | `stroke-linecap` | `round` |
| Non-scaling stroke | `vector-effect` | `non-scaling-stroke` |
| Opacity | `opacity` | `obj.opacity` or `1` |

### Type 5: Arrows

| Property | SVG Attribute | Value |
|----------|---------------|-------|
| Container | `<g>` | Groups line + arrowhead |
| Line element | `<line>` | Same as Type 4 |
| Arrowhead element | `<polygon>` | `points="0,{-headSize/2} {headSize},0 0,{headSize/2}"` |
| Arrowhead size | -- | `max(6, strokeWidth * 3)` in page coordinate units |
| Arrowhead transform | `transform` | `translate({x2}, {y2}) rotate({angle})` where angle = `atan2(dy, dx)` in degrees |
| Arrowhead fill | `fill` | Same as line stroke color |

### Type 6: Shapes (Rect, Circle/Ellipse)

**Rect:**

| Property | SVG Attribute | Value |
|----------|---------------|-------|
| Element | `<rect>` | -- |
| Position | `x`, `y` | `obj.left`, `obj.top` |
| Size | `width`, `height` | `abs(obj.width * obj.scaleX)`, `abs(obj.height * obj.scaleY)` |
| Rotation | `transform` | `rotate({angle}, {left}, {top})` if angle != 0 |
| Fill | `fill` | `obj.fill` or `transparent` |
| Stroke | `stroke` | `obj.stroke` or `transparent` |
| Non-scaling stroke | `vector-effect` | `non-scaling-stroke` when `obj.strokeUniform === true` |
| Highlight detect | -- | `globalCompositeOperation === 'multiply'` triggers `mix-blend-mode: multiply` |

**Circle/Ellipse:**

| Property | SVG Attribute | Value |
|----------|---------------|-------|
| Element | `<ellipse>` | Always use ellipse (handles both circle and ellipse JSON types) |
| Center | `cx`, `cy` | `obj.left + rx`, `obj.top + ry` |
| Radii | `rx`, `ry` | For circle: `obj.radius * abs(obj.scaleX)`, `obj.radius * abs(obj.scaleY)`. For ellipse: `obj.rx * abs(obj.scaleX)`, `obj.ry * abs(obj.scaleY)` |

### Type 7: Text (via foreignObject)

| Property | SVG/HTML Attribute | Value |
|----------|-------------------|-------|
| SVG element | `<foreignObject>` | -- |
| Position | `x`, `y` | `obj.left`, `obj.top` |
| Size | `width`, `height` | `abs(obj.width * obj.scaleX)`, `abs(obj.height * obj.scaleY)` |
| Rotation | `transform` | `rotate({angle}, {left}, {top})` if angle != 0 |
| Inner element | `<div xmlns="http://www.w3.org/1999/xhtml">` | Required namespace for foreignObject HTML |
| Font size | `font-size` | `{obj.fontSize}px` or `16px` |
| Font family | `font-family` | `obj.fontFamily` or `sans-serif` |
| Font weight | `font-weight` | `obj.fontWeight` or `normal` |
| Text color | `color` | `obj.fill` or `#000000` |
| Text align | `text-align` | `obj.textAlign` or `left` |
| Line height | `line-height` | `obj.lineHeight` or `1.16` |
| White space | `white-space` | `pre-wrap` |
| Word wrap | `word-wrap` | `break-word` |
| Overflow | `overflow` | `hidden` |
| Box sizing | `box-sizing` | `border-box` |
| Padding | `padding` | `0` |

### Callouts (special: separate data source)

| Property | SVG Element | Value |
|----------|-------------|-------|
| Coordinate system | -- | Normalized (0-1) multiplied by `pageWidth`/`pageHeight` (unscaled) |
| Connection lines | `<line>` | Two segments from `calculateCalloutConnection()`: arrowTip-to-knee, knee-to-borderPoint |
| Arrowhead circle | `<circle>` | At arrowTip position, `r=3`, filled with line color |
| Text box | `<rect>` + `<foreignObject>` | Rect with `callout.style.fillColor`, text inside foreignObject |
| Line stroke | `stroke` | `callout.style.lineColor` or `#4A90E2` |
| Line width | `stroke-width` | `callout.style.lineThickness` or `2` |
| Non-scaling stroke | `vector-effect` | `non-scaling-stroke` |
| Text box fill | `fill` | `callout.style.fillColor` or `rgba(255, 255, 255, 0.22)` |
| Text box border | `stroke` | `callout.style.lineColor` or `#4A90E2` |
| Text box border radius | `rx`, `ry` | `4` (matches existing overlay) |

## Copywriting Contract

This phase has minimal user-facing copy. All copy is developer-facing (renderer toggle) or system-level.

| Element | Copy |
|---------|------|
| Toggle badge (SVG active) | `SVG` |
| Toggle badge (Canvas active) | `CANVAS` |
| Console log on toggle | `[Renderer] Switched to {svg|canvas} mode` |
| Console log on mount | `[SVGAnnotationLayer] Mounted for page {N} with {count} annotations, {count} callouts` |
| Empty state | No visible empty state -- when a page has zero annotations, the SVG element renders with no children (invisible to user) |
| Error state | No user-facing error state -- rendering errors are caught by ErrorBoundary (existing component) and logged to console: `[SVGAnnotationLayer] Render error on page {N}: {message}` |
| Destructive actions | None in this phase (display-only, no editing) |

## Renderer Toggle Visual Spec

The renderer toggle is a developer tool visible during the v2.0 development period (Phases 8-11). It is removed after v2.0 ships.

### Badge Appearance

| Property | Value |
|----------|-------|
| Position | Fixed, bottom-right corner of viewport |
| Offset from edge | 8px right, 8px bottom |
| Padding | 4px 8px |
| Border radius | 4px |
| Font | `12px/1.0 monospace` at weight 600 |
| Z-index | `99999` (above all PDF layers) |
| Opacity | `0.85` |
| Pointer events | `auto` (clickable to toggle) |
| Cursor | `pointer` |

### Toggle Interaction

| Trigger | Behavior |
|---------|----------|
| URL parameter `?renderer=svg` | Starts in SVG mode |
| URL parameter `?renderer=canvas` | Starts in Canvas mode |
| No URL parameter | Defaults to `canvas` (safe default during development) |
| Keyboard shortcut `Ctrl+Shift+V` | Toggles between SVG and Canvas mode |
| Click on badge | Toggles between SVG and Canvas mode |
| Toggle effect | When SVG: PAL does NOT mount (saves ~44MB/page). When Canvas: SVGAnnotationLayer does NOT mount, PAL mounts normally |

## Visibility Filtering Contract

SVGAnnotationLayer must implement the same three-layer filtering as PAL. This is the visual contract for what annotations are visible under each state combination.

### Layer 1: Base annotations (no moduleId, no regionId)

| State | Visible? |
|-------|----------|
| No survey panel open | Yes |
| Survey panel open, no module selected | Yes |
| Survey panel open, module selected | Hidden (obscured by module layer) |

### Layer 2: Module annotations (has moduleId)

| State | Visible? |
|-------|----------|
| No survey panel open | Hidden |
| Survey panel open, module matches selectedModuleId | Yes |
| Survey panel open, module does NOT match | Hidden |

### Layer 3: Region annotations (has regionId)

| State | Visible? |
|-------|----------|
| No active space | Hidden |
| Active space, region overlay enabled, has active regions | Yes (if region matches) |
| Active space, specific activeRegionId set | Visible only if regionId matches |

### Lightbulb Toggle (background annotations)

| State | Visible? |
|-------|----------|
| No active space | Always visible |
| Active space, lightbulb ON for page | Visible |
| Active space, lightbulb OFF for page | Hidden |

### Layer Visibility

| State | Visible? |
|-------|----------|
| `layerVisibility[obj.layer]` is `false` | Hidden |
| `layerVisibility[obj.layer]` is `true` or undefined | Visible |

## Visual Fidelity Acceptance Criteria

These criteria define "correct rendering" for the checker and auditor.

| Criterion | Acceptable | Not Acceptable |
|-----------|-----------|----------------|
| Position accuracy | Annotations at correct positions matching Canvas output | Annotations shifted by 50-200px (pathOffset bug) |
| Size accuracy | Annotations at correct size matching Canvas output | Highlights too small/large (missing scaleX/scaleY) |
| Color accuracy | Exact color match (same hex values from JSON) | Wrong colors or missing opacity |
| Stroke width at zoom | Constant thickness via non-scaling-stroke | Strokes thickening/thinning during zoom |
| Highlight blending | `mix-blend-mode: multiply` matches Canvas compositing | Opaque rectangles obscuring PDF text |
| Text rendering | Content, position, font, size, color correct | Wrong font, wrong position, clipped text |
| Text word-wrap | Minor differences from Fabric IText acceptable | Missing text content or totally wrong wrapping |
| Anti-aliasing | Minor differences from Canvas acceptable | Not applicable (browser handles this) |
| Sub-pixel rendering | Minor differences acceptable | Not applicable |
| Erased annotations | Erased regions correctly absent; remaining parts visible | Erased annotations fully visible or fully missing |
| Zoom behavior | Smooth scaling, zero flicker, zero disappearance | Annotations disappear, flash, or reposition during zoom |
