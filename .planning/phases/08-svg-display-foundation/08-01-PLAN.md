**Step 1: Create `src/utils/svgAnnotationRenderers.js`**

Create a utility module exporting pure render functions for each annotation type. Each function takes a Fabric.js JSON object and returns a React SVG element. Use named exports (no default export), consistent with project conventions.

Helper functions to include at top of file:
- `toNumber(value, fallback)` -- same as LightweightAnnotationOverlay's helper
- `isErasedOutline(obj)` -- returns true when `obj.strokeWidth === 0 && obj.fill && obj.fill !== 'transparent'` (erased path detection, used in Plan 02 but define now)

**`renderPath(obj, index)`** -- Pen strokes and highlighter strokes:
- Build SVG `<path>` element
- Path data `d`: `obj.path.map(seg => seg.join(' ')).join(' ')`
- Transform chain (CRITICAL -- pathOffset): `translate({left}, {top}) rotate({angle}) scale({scaleX}, {scaleY}) translate({-pathOffset.x}, {-pathOffset.y})`
  - `left = obj.left ?? 0`, `top = obj.top ?? 0`
  - `angle = obj.angle ?? 0` -- only include `rotate(angle)` if angle !== 0
  - `scaleX = obj.scaleX ?? 1`, `scaleY = obj.scaleY ?? 1` -- only include `scale()` if not both 1
  - `pathOffset.x = obj.pathOffset?.x || 0`, `pathOffset.y = obj.pathOffset?.y || 0`
- Detect highlight: `obj.globalCompositeOperation === 'multiply'`
- Detect erased outline: `isErasedOutline(obj)` -- if true, use `fill={obj.fill}`, `stroke="none"`, `fillRule="evenodd"`; otherwise use `stroke={obj.stroke || '#000'}`, `fill="none"`
- `strokeWidth={obj.strokeWidth || 1}` (for non-erased paths)
- `strokeLinecap="round"`, `strokeLinejoin="round"`
- `vectorEffect={obj.strokeUniform ? 'non-scaling-stroke' : undefined}`
- `opacity={obj.opacity ?? 1}`
- `style={isHighlight ? { mixBlendMode: 'multiply' } : undefined}`
- Key: `path-${obj.id || obj.highlightId || obj.pdfAnnotationId || index}`

**`renderRect(obj, index)`** -- Rectangles (shapes + highlights):
- Build SVG `<rect>` element
- `x={obj.left}`, `y={obj.top}`
- `width={Math.abs((obj.width || 0) * (obj.scaleX || 1))}`, `height={Math.abs((obj.height || 0) * (obj.scaleY || 1))}`
- Rotation: `transform={obj.angle ? \`rotate(${obj.angle}, ${obj.left}, ${obj.top})\` : undefined}`
- `fill={obj.fill || 'transparent'}`, `stroke={obj.stroke || 'transparent'}`
- `strokeWidth={obj.strokeWidth || 0}`, `opacity={obj.opacity ?? 1}`
- `vectorEffect={obj.strokeUniform ? 'non-scaling-stroke' : undefined}`
- Highlight detection: `obj.globalCompositeOperation === 'multiply'` triggers `style={{ mixBlendMode: 'multiply' }}`
- Key: `rect-${obj.id || obj.highlightId || index}`

**`renderLine(obj, index)`** -- Standalone lines:
- Build SVG `<line>` element
- Coordinates: `x1={obj.left + (obj.x1 || 0)}`, `y1={obj.top + (obj.y1 || 0)}`, `x2={obj.left + (obj.x2 || 0)}`, `y2={obj.top + (obj.y2 || 0)}`
- `stroke={obj.stroke || '#000'}`, `strokeWidth={obj.strokeWidth || 2}`
- `strokeLinecap="round"`, `vectorEffect="non-scaling-stroke"`
- `opacity={obj.opacity ?? 1}`
- Key: `line-${obj.id || index}`

**`renderArrow(obj, index)`** -- Arrow groups (line + triangle arrowhead):
- Build SVG `<g>` containing `<line>` + `<polygon>`
- Find child line: `obj.objects.find(o => o && (o.type === 'line' || o.type === 'polyline' || o.type === 'path'))`
- Find arrowhead: `obj.objects.find(o => o && (o.name === 'arrowHead' || o.type === 'triangle'))`
- If no lineChild, return null
- Line coordinates: `x1 = (obj.left || 0) + (lineChild.x1 || 0)` etc.
- Arrow angle: `Math.atan2(dy, dx) * (180 / Math.PI)`
- Arrow head size: `Math.max(6, (obj.strokeWidth || 2) * 3)`
- Polygon points: `0,{-headSize/2} {headSize},0 0,{headSize/2}`
- Polygon transform: `translate({x2},{y2}) rotate({angle})`
- `vectorEffect="non-scaling-stroke"` on the line
- `opacity={obj.opacity ?? 1}` on the `<g>`
- Key: `arrow-${obj.id || index}`

**`renderEllipse(obj, index)`** -- Circle/Ellipse (stub for Plan 02, export now):
- Placeholder that renders a basic `<ellipse>` element
- For circle type: `rx = (obj.radius || 0) * Math.abs(obj.scaleX || 1)`, same for ry with scaleY
- For ellipse type: `rx = (obj.rx || 0) * Math.abs(obj.scaleX || 1)`, `ry = (obj.ry || 0) * Math.abs(obj.scaleY || 1)`
- `cx = obj.left + rx`, `cy = obj.top + ry`
- Key: `ellipse-${obj.id || index}`

**`renderText(obj, index)`** -- Text stub for Plan 02, export now:
- Return null (placeholder)

**`renderCallout(callout, index, pageWidth, pageHeight)`** -- Callout stub for Plan 02, export now:
