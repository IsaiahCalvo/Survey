<context>
The key architectural insight: the Syncfusion page containers survive zoom (overlayLayerRefCount stays at 7, missingOverlayCount stays at 0). The portals are NOT destroyed during zoom. The real problem is that the Fabric.js canvas inside PageAnnotationLayer was being continuously resized (setWidth/setHeight/setZoom/requestRenderAll) on every zoom tick because the `scale` prop changes rapidly. This expensive operation blanks the canvas content momentarily, and with continuous zooming, annotations appear to disappear.

The fix strategy: when `isZooming` is true, skip the expensive Fabric.js canvas resize and instead apply a CSS `transform: scale(ratio)` to the Fabric.js canvas container element for GPU-accelerated visual scaling. When zoom settles (140ms debounce in useZoomState), remove the CSS transform and do one final canvas resize to the settled scale.

Key files:
- `src/App.jsx` line 9117: `useZoomState` destructuring (added `isZooming`, `cssScale`)
- `src/App.jsx` line ~23399: `isZooming={isZooming}` prop passed to PageAnnotationLayer
- `src/PageAnnotationLayer.jsx` line ~7657: zoom deferral logic with CSS transform on `fabricRef.current.wrapperEl`
- `src/hooks/useZoomState.js`: provides `isZooming` (true when `Math.abs(cssScale - 1) > 0.001`), debounces `renderedScale` by 140ms
</context>
