<decisions_made>

- FIXED iteration 5: Removed `scaleJump > 0.05` deadlock. The guard created a permanent deadlock where canvas zoom never updated because the guard prevented the very resize that would reduce scaleJump.
- ADOPTED `inZoomModeRef` latch pattern: Once zoom starts (`isZooming || scaleJump > 0.01`), we stay in CSS-transform-only mode until the settle timer fires AND completes. Prevents expensive resize mid-zoom even when `isZooming` flickers false between scroll-wheel events.
- INCREASED settle timer from 300ms to 500ms: Telemetry showed gaps of 300-800ms between zoom-out scroll events. 300ms was too short — timer fired mid-zoom.
- ADDED snapshot double-buffer: `drawImage` from `lowerCanvasEl` to temp canvas before resize. Covers the blank period while `setWidth`/`setHeight` clears pixel buffer and `renderAll` repaints (~500ms). drawImage is GPU-accelerated (~1ms).
- KEY INSIGHT from telemetry: Zoom-IN is fast (19-55ms frames, CSS transform working), Zoom-OUT is slow (300-800ms frames). During zoom-out, `isZooming` (from useZoomState's 140ms debounce) flickers false between wheel events, causing the effect to fall through to the expensive resize path.
</decisions_made>

<context>
Architecture:
- Syncfusion PDF Viewer renders pages. Custom PageAnnotationLayer (Fabric.js canvas) overlays annotations via React portals into Syncfusion page containers.
- During zoom, Syncfusion re-renders pages. The `scale` prop to PAL (`layerScale`) changes continuously.
- `useZoomState(scale)` in App.jsx produces `isZooming` (true when `cssScale = targetScale/renderedScale` differs from 1 by >0.001, with 140ms debounce).
- `isZooming` is passed as prop to PAL. PAL's scale useEffect uses it to decide: CSS transform (fast) vs canvas resize (slow).

The zoom flow:
1. User zooms -> Syncfusion fires zoomChange -> app `scale` state updates
2. `useZoomState(scale)` computes isZooming, cssScale
3. `layerScale` = DOM-measured page scale (via `getSyncfusionPageScale`)
4. PAL receives `scale={layerScale}`, `isZooming={isZooming}`
5. PAL useEffect: if `inZoomModeRef.current` -> CSS transform; else -> canvas resize

Key files:
- `src/App.jsx` line 9117: `useZoomState(scale)` -> provides `isZooming`
- `src/App.jsx` line ~23400: `isZooming={isZooming}` prop to PAL
- `src/PageAnnotationLayer.jsx` line ~7659: The scale useEffect with zoom logic
- `src/hooks/useZoomState.js`: `isZooming` = `Math.abs(cssScale - 1) > 0.001`, debounce 140ms

Current state of the scale useEffect (iteration 7):
- `inZoomModeRef` latch: entered on `isZooming || scaleJump > 0.01`, cleared only by settle timer callback after successful render
- CSS transform applied to `canvas.wrapperEl` with `scale(ratio)` + red debug outline
- 500ms settle timer with snapshot double-buffer (drawImage to temp canvas before resize)
- Direct resize path only reached when NOT in zoom mode AND scaleJump < 0.01
</context>
