<context>
Architecture after all changes:

1. handleSyncfusionZoomChange (App.jsx ~11604): Synchronously applies CSS scale(ratio) to overlay content divs. Captures base scale on first zoom event. 1s safety timer fallback.

2. PAL scale effect (~7688): When inZoomModeRef latched, defers resize via 300ms settle timer. Only resets timer when scale actually changes. NO CSS transforms (App handles it).

3. Settle callback (three-tier):
   - Center page (contains viewport center Y): enqueueZoomResize → double-rAF → Fabric render
   - Visible non-center: CSS wrapper scale + 800ms setTimeout → enqueueZoomResize
   - Off-screen: CSS wrapper scale + IntersectionObserver → enqueueZoomResize

4. Stagger queue (_zoomResizeQueue in PAL ~3052): Module-level shared. Drains one callback per double-rAF (two requestAnimationFrame calls). Ensures browser paints CSS-scaled state before each heavy render.

5. handlePALScaleApplied (App.jsx ~10053): Called when PAL finishes resize. Removes CSS transform from that page's overlay content div.
