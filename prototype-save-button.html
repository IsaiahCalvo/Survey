Blank-input fix — proposal

Type something to add it. Try leaving one blank and pressing Enter or clicking out.

Can't be empty — type a name or remove the row.
How it works: Each new row has greyed placeholder text so you know what to type. If you hit Enter or click away with the input still blank, the bottom edge of the input briefly flashes red and softly shakes once, and a small "Can't be empty" hint slides in under it. The row never commits until you've typed real text. For existing items, clearing the text and clicking away quietly reverts to the previous value — so you can't accidentally delete a row just by blanking it.
