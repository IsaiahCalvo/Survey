Mobile Survey + Spaces/Regions UI Explorations

Goal: survey, spaces/regions, and annotations can each work independently, but can also be opened together without turning the phone into a cockpit.

Best path: phone = sheets + chips, tablet = true docked panels

Option A — Twin Bottom Sheets

Most phone-native. Survey + Spaces are sibling sheets. One can be half-open while the other is pinned as a chip.

Recommendation

Ship a hybrid: Option A as default phone UI, Option B as explicit “Combo” mode, Option C for tablet/landscape/foldables, and Option D for selected-object interactions. Surveys and Spaces stay independent siblings; selection can cross-highlight/filter, but never require the other panel.
