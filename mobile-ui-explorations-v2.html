My updated recommendation

Use a PDF editor shell: canvas + annotation toolbar are always primary. Add a Panel Drawer for Pages/Search/Bookmarks/Layers/Spaces/Survey/Revisions/Export. Phone defaults to one sheet at a time + contextual cards; phone has an explicit Combo Workbench when Survey + Spaces both need to be open; tablet gets real side panels.

Research references that actually fit this better

Bluebeam Revu — best construction/PDF reference: Spaces, Layers, Sets, Markups List as separate panels around PDF. Spaces · Layers · Markups
PDF Expert / Acrobat / Xodo — mainstream mobile PDF model: document first, annotation/search/page/export actions around it. PDF Expert · Acrobat mobile · Xodo
Goodnotes / Notability / Drawboard — persistent pen/highlighter/eraser toolbar; panels are secondary. Goodnotes · Notability · Drawboard
Procreate / Concepts / Figma — canvas-first with compact layers, inspectors, and object-specific controls. Procreate Layers · Concepts Layers · Figma UI
