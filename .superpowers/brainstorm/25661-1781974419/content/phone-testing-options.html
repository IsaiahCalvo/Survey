Phone Testing Setup

Recommended path for designing and testing the iPhone app live.

A

Use Tailscale + Browser Preview First

Fastest for UI layout. Open the dev/mock URL on the phone over Tailscale. Good for checking responsive layout, touch target size, safe areas, panels, and toolbar density.

Phone URL: http://100.113.236.18:53499

B

Capacitor Dev App, Expo-Style

Best for real app testing. Install the native iOS shell once, then point it at the Vite dev server over Tailscale or LAN. Feels closest to Expo Dev Client: native wrapper, live web reload.

C

QR Launcher Helper

Add a local dev page that shows QR codes for browser preview and installed native app URLs. It will not install an iOS native app by itself, but it removes typing URLs.

My Recommendation

Start with A for layout decisions today. Build B into the dev workflow before implementation QA. Add C as a small helper so you can scan instead of typing URLs.
