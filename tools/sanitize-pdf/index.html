Questions

What hidden data can a PDF have?

The author's name, the title, when it was made and changed, the app used, hidden XMP metadata, scripts that run when it opens, and files attached inside it.

Will the pages look different?

No. Text, drawings, images, links and form fields stay just as they are. Only the hidden parts are taken out.

Can I do several files at once?

Yes. Choose or drop several files. Each one gets the same settings, and you save them all in one ZIP.

Are old versions of the file removed too?

Yes. Some PDFs keep earlier saved versions inside them. The clean copy is written fresh, so only what you see is kept.

Does it remove things shown on the page?

No. A name or logo printed on the page is part of the page and stays. Tick "Comments and markups" to take off notes and highlights.

Are my files uploaded?

No. The tool runs in your browser, so your files never leave your device. Nothing is sent to us or kept after you close the tab.

Is it free?

Yes. There is no sign-up, no watermark on your file and no daily limit.

Does it work offline?

Yes. Once the page has loaded you can turn off Wi-Fi and the tool still works.
